# 取证台账与证据链

本文件是反幻觉的执行层。**它优先级高于报告好不好看。**

一句话原则：**写不出六行，就不许进正文。**

---

## 一、五级证据

| 级 | 定义 | 举例 | 能否单独支撑结论 |
|---|---|---|---|
| **S** | 原始一手文件 | 项目立项备案原件、土地出让合同、控规图则原件、批复扫描件、企业未公开报表、现场实测记录（拍照+时间戳）、会议纪要、方案图 | ✅ **对持有者成立**；对外不可复核，须附原件编号与页码 |
| **A** | 官方发布 | 统计年鉴、统计公报、政府工作报告、部委/省市文件原文、官方名单公示、政府新闻发布会实录、法院裁判文书 | ✅ 可 |
| **B** | 权威二手（可核验的机构出品） | 上市公司年报与招股书、行业协会年度报告、OTA 公开票价与点评量、产权交易所/司法拍卖公告、企业信用公示 | ✅ 可（限其自身口径范围内） |
| **C** | 一般二手 | 主流媒体报道、券商与咨询研报、专业公众号、地方自媒体、百科条目的引注 | ⚠️ **须两源互证**，且至少一源能指到原始出处 |
| **D** | 推断/常识 | 专家经验、类比同城同类、行业惯例、作者判断 | ❌ 不得单独支撑任何结论，必须标「推断」并挂 ≥1 个 B 级以上佐证 |

### 三条降级规则

1. 出现「数据显示」「据测算」「业内普遍认为」而指不出原始发布者的，**一律降 D**；指不出则删。
2. C 级被另一家媒体转载，**不升 B**——转引不是核验。
3. A 与 C 冲突时**以 A 为准并记录分歧**，不许用 C 把数字说圆。

## 二、证据链六行格式（强制）

每个进入结论的事实或数字，在台账里占一行六段，一段不缺：

```
〔结论〕……
〔证据〕……（数值/原文关键句/事实陈述）
〔出处〕发布主体 + 文件名 + 章节/页码 + 链接
〔获取日期〕YYYY-MM-DD
〔级别〕S/A/B/C/D
〔反证〕有/无；有则写：〈相反证据 + 出处 + 为什么不推翻本结论〉
```

### 填好的样例

```
〔结论〕某文旅项目所在市，20XX 年接待游客量已恢复并超过 2019 年水平，客源以省内自驾为主
〔证据〕2024 年全市接待游客 4,320 万人次，同比 +18.6%；其中省内客源占 63%，自驾出行占 71%
〔出处〕〈某市〉2024 年国民经济和社会发展统计公报，第三部分「旅游」，第 12 页，https://...（原文：「全年接待游客 4,320 万人次，比上年增长 18.6%」）
〔获取日期〕2026-10-27
〔级别〕A（人次与增速）／B（客源结构，取自市文旅局 2024 年度通报）
〔反证〕有。另一来源（省级文旅厅季度通报）同期数为 3,980 万人次，差异 8.5%，系「全域旅游人次」与「购票入园人次」口径不同；本结论采用统计公报口径，并在正文注明
```

**验收标准**：把这一行交给第三方，他能顺着出处找到同一段原文，并且知道分歧在哪。

### 台账怎么存

- 内部工件 `取证台账.md`，一行一条，按章节分组（政策／规划／市场／案例／其他）
- 台账不进交付四件，但**必须与报告一同留档**，下游质询时第一时间调出来
- 已废弃的条目**不删**，标 `〔作废：原因〕`——删掉就查不出当时的判断路径

## 三、三源验证法

### 什么数必须做

只有「关键数字」要做：会进结论、且下游会据此做定案判断的（客流量级、票价、投资额、市占率、增长率、人均消费、保本门槛）。其余数字单源 A/B 即可。

### 怎么算「独立来源」

| 算独立 | 不算独立 |
|---|---|
| 不同发布主体，各自有原始采集 | 同一条通稿被 20 家媒体转载（= 1 源） |
| 统计局与文旅厅各自口径 | 媒体 A 引媒体 B，B 引媒体 A |
| 年报与政府通报（主体不同） | 同一集团内不同公众号 |
| 现场实测与官方公布 | 一份研报与其引用的同一份研报 |

**最低配置**：3 个来源中，至少 2 个发布主体不同，且至少 1 个是 A 或 B。

### 冲突怎么记（不取平均、不择一）

```
〔冲突〕〈指标名〉
〔源1〕级别｜发布主体｜数值｜口径｜日期
〔源2〕级别｜发布主体｜数值｜口径｜日期
〔源3〕级别｜发布主体｜数值｜口径｜日期
〔差异〕最大差 __%，方向是否一致：一致／分歧
〔可能原因〕口径不同／统计范围不同／时点不同／含过境或二次计数
〔处理〕本报告采用 __ 口径，理由 __；其余数值在正文脚注列出
```

- **禁止取平均**——平均出来的数没有任何机构发布过，等于自造数据
- **禁止择一而不说明**——被弃用的数一定要出现在脚注，否则读者以为只有一种说法
- 三源方向不一致（有的涨有的跌）时，**结论降级为「方向不明」**，不要挑一个支持自己想法的

### 反向验证（易被跳过，必须做一次）

对每个将支撑建议的乐观判断，主动找一次相反证据：有没有同类项目客流远低于宣传、有没有停业/流拍/重整、有没有「已达上限」的官方表述。**报告里至少要出现一次明确写出反向验证结果的地方。**

## 四、《取证局限》四段写法

它不是免责声明，是**价值证明**：告诉下游哪些结论现在能用，哪些用了会出事。

```
## 取证局限

### 1. 查了什么（缺口）
本次未能取得 S/A/B 级证据的事项共 __ 项，见下表。

| 项 | 为什么它重要 | 影响的结论 | 缺了会怎样 |
|---|---|---|---|

### 2. 试过哪些入口（可复核）
- 〈域名/平台〉：检索式 `……`，检索日期 YYYY-MM-DD，命中 __ 条，无一含所需数据
- 〈平台〉：需登录/需付费，未获取

### 3. 为什么受限
□ 政府未公开　□ 属企业经营数据不对外　□ 需授权或付费　□ 统计口径未发布　□ 时效未到（年报未出）　□ 该地无此统计项

### 4. 对结论的影响
- 结论「__」由 __ 级降为 __ 级，表述改为「__」
- 结论「__」暂停判断，待 __ 方补充 __ 后重算
- 需要委托方补充：〈清单〉
```

**必须写具体检索式与日期。** 写「多方查找未果」的，视为没查。

## 五、交给下游时的降维映射

下游按两态口径复核。转换规则如下，转换后仍要保留原始级别（写在括号里），不许抹掉。

| 原级 | 降维标签 | 下游看到的意思 |
|---|---|---|
| A | **有出处** | 可顺链核到官方原文，可直接用 |
| B | **有出处** | 可顺链核到机构原始页，可直接用（限其口径） |
| C | **有出处（须两源互证）** | 单条 C 不放行；两条独立 C 且能指原始出处才放行 |
| D | **推断** | 不得作为定案依据，只能作讨论起点 |
| S | **推断（内部一手，未外部核验）** | 附原件编号/页码；下游无法复核，须 ≥1 个 A/B 佐证才可承重 |

### 转换时的三条硬规矩

1. **不许升级**：C 不能因为「看起来可信」写成「有出处」；S 不能因为「是原件」写成「有出处」。
2. **不许隐级**：正文引用处保留小标，如 `（A｜某市统计公报 2024）`，降维只发生在交接说明里。
3. **推断必须成句可辨**：写「推断：__」，不许写成陈述句混在实证里。一条推断句里如果夹了数字，那个数字必须另有出处。

## 六、禁止行为

1. 编造数据、来源、文件名、机构名、政策条款号
2. 用记忆或联想填数（凡凭印象，一律 D 且不得进结论）
3. 把「业内通常」「行业惯例」当证据用
4. 为凑满案例数或政策条数，把推断写成实证
5. 查不到却装作查到（最严重，一次即全稿失信）
6. 用「建议进一步研究」代替具体缺口说明
7. 把委托方口径当作已外部核验的数据
8. 用绝对化结论（「必然失败」「一定成功」）——研究给的是有条件的判断
