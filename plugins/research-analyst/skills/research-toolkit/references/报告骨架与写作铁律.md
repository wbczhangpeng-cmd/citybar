# 报告骨架与写作铁律

本文件管两件事：**每一章必须有什么**，**哪些话不许写**。正文 1.2–1.8 万字（不含附录、台账、卡片）：低于 1.2 万说明证据不够，高于 1.8 万说明没收敛。

---

## 一、六章配比与必含项

| 章 | 必含项（缺一即不合格） | 字数 | 占比 |
|---|---|---|---|
| 摘要页 | 见第三节，≤600 字 | ≤600 | 另计 |
| ① 研究命题与范围 | 命题一句话；要回答的 3–5 个问题；空间范围（半径或行政区）；时间范围与资料截止日；**不研究什么** | 1,000–1,400 | ~8% |
| ② 政策（国/省/市三层） | 条数下限：国 10–20、省 8–20、市 8–20；**按红线/可争取/背书重组**；政策窗口期小节 | 2,800–3,600 | ~22% |
| ③ 上位规划与合规约束 | 总规/控规/专项规划各自约束条款；用地性质与强度（容积率、限高、绿地率、退线）；审批链条（谁批什么、先后）；6–10 条硬约束清单 | 1,600–2,200 | ~13% |
| ④ 案例 | 成功 8–12 + 失败 2–3；每案一卡片；末段《借鉴清单》12–20 条三段式 | 3,600–5,000 | ~30% |
| ⑤ 市场与客群 | 大盘（客流/收入/增速，三源）；客源结构（地域/出行/停留时长/人均花费）；竞品供给表；季节性曲线；需求缺口 | 1,800–2,400 | ~15% |
| ⑥ 启示与建议 + 取证局限 | 定位/业态/运营三段建议，每条带依据；取证局限四段 | 1,400–2,000 | ~12% |

### 各章合格 / 不合格对照

| 章 | 不合格 | 合格 |
|---|---|---|
| ① | 「随着文旅融合战略深入推进，本项目研究具有重要现实意义。」 | 「本报告回答四问：一、该市近三年过夜游客增速能否持续；二、2 小时车程内是否已有同质供给；三、控规限高与容积率能否支撑设想体量；四、近五年可对标案例中哪一类在同类区位跑通。**不研究**：建筑方案、投资测算、运营主体选择。」 |
| ② | 按发文时间从 2019 罗列到 2025，共 42 条，每条一段摘要。 | 「红线 6 条、可争取 9 条、背书 11 条。红线第 3 条：〈文号〉第 X 条『……』——地块位于 __ 保护区一般控制区，禁止 __。」 |
| ③ | 「项目符合上位规划要求。」 | 「控规图则（〈批复文号〉）四项指标：用地性质 A2、容积率 ≤1.2、限高 15m、绿地率 ≥35%。限高与设想的三层观景台（需 18m）冲突，需走 __ 程序。」 |

| ⑤ | 「目标客群覆盖全年龄段、全时段。」 | 「工作日：本市 3 区 30–45 分钟车程的亲子家庭，停留 3–4 小时，人均 60–90 元；周末：省内 2 小时圈自驾，停留 1 晚，人均 300–450 元；节庆：过境团队，停留 2 小时，人均 40 元以下。依据：〈客流分时数据〉〈住宿订单结构〉。」 |

## 二、政策章：按判定重组，不按时间罗列

罗列政策是这一章最典型的废法——读者拿不到任何可操作结论。重组固定为三栏：

| 判定 | 定义 | 每条必须写 |
|---|---|---|
| **红线** | 明确禁止或严格限制，动了就出局 | 文号 + 条款原文摘句（≤30 字）+ 禁止什么 + 越线后果（罚则/不予审批） |
| **可争取** | 有弹性空间，需走程序或满足条件 | 文号 + 弹性点在哪个字句 + 争取路径（找谁、报什么、需什么材料）+ 成功先例 |
| **背书** | 可作叙事、申报、争取资源的依据 | 文号 + 可引用的表述 + 适用场景 |

三条纪律：① 每条都要有原文摘句，不许只写文件名；② 红线必须写后果，只写「受限」等于没说；③ 政策窗口期单独一节，列近 3 年到期/修订/新出的文件，说明「现在做与两年后做有什么不同」。

配套 `政策清单.csv` 九列固定，每条都要能在正文三栏找到归属，找不到的就是没判过。

## 三、摘要页：≤600 字，只回答「改变了什么判断」

下游只看这一页。它不许是正文缩写，必须写成**判断的前后对比**：

```
### 一页结论

**结论**：〈一句话，含一个可核验的数或一个明确方向〉

**这份研究改变了三个判断**
1. 原本以为 __，实际 __（依据：__，__ 级）
2. 原本以为 __，实际 __（依据：__）
3. 原本以为 __，实际 __（依据：__）

**三件必须现在决定的事**
1. __（不决定的后果：__）
2. __
3. __

**两件还不确定的事**
1. __（缺什么数据、谁能补）
2. __
```

- 某条若是「原本以为要研究、实际研究了」——删掉，那不是判断
- 每条对比必须挂级别标（A/B/C/D/S），挂不上的只是印象
- **通篇不出现「建议进一步研究」「具有重要意义」「打造标杆」**；超 600 字先砍第二段，不砍第四段

## 四、建议章：只给建议，不给定案

我在第一棒，定案权在下游。每条建议写成「建议 + 依据 + 三条确认」：

```
**建议一（定位）**：__
- 依据：〈指向前五章的具体条目〉
- 若采纳，下游需确认：① __ ② __ ③ __

> 以上为研究侧建议，最终方案由下游定案。本报告只对建议所依据的事实与出处负责。
```

三条纪律：① 每条建议必须挂依据，指不回前五章的删；② 不写「应该定成 __」，写「若定成 __，需先确认 __」；③ 不越界——不做视觉、不做 PPT、不写汇报稿、不做投资测算与建筑方案，被要求时回「超出本棒范围」。

## 五、写作铁律：禁用表述清单

| 禁用 | 为什么 | 改成 |
|---|---|---|
| 「随着 __ 战略的深入推进」 | 零信息量开头 | 直接写条款、数字或事实 |
| 「具有重要意义」「影响深远」 | 结论空转，无法检验 | 写对谁、什么意义、怎么验证 |
| 「打造 __ 新高地／标杆／样板」 | 口号，无法验收 | 写目标客群 + 可比对象 + 量化目标 |
| 「深入分析」「综合考虑」「统筹兼顾」 | 不可执行 | 写用了什么方法、权衡了哪两项、偏向哪边 |
| 「据测算」「数据显示」（无出处） | 造假高发区 | 补出处 + 日期，补不上就删 |
| 「业内普遍认为」「行业惯例」 | 不可核 | 指名机构与报告，或标 D 级 |
| 「有望」「或将」+ 数字 | 模糊词包装预测 | 写情形（乐观/中性/保守）+ 触发条件 |
| 「填补空白」「全国首创」 | 需证明穷尽检索 | 写比对范围 + 检索日期 + 检索式 |
| 「建议进一步研究」 | 把缺口推给下游 | 写清缺什么、谁能补、影响哪条结论 |
| 「约」「左右」「大幅度」滥用 | 掩盖精度 | 写实际精度或说明区间来源 |
| 「不仅仅是 __，更是 __」 | 修辞代替论证 | 拆成两个可证伪的陈述 |

另三条正面要求：每段首句是结论句；一个数字全文只一种口径；推断句以「推断：」开头。

## 六、交付前总检（5 分钟）

- [ ] 六章齐全，1.2–1.8 万字，摘要 ≤600 字
- [ ] 政策 30–60 条，CSV 九列齐全，每条在三栏有归属
- [ ] 案例 8–12 成功 + 2–3 失败，每案 ≥3 条「做法+证据」
- [ ] 《借鉴清单》12–20 条三段式，验收标准含数字或检查对象
- [ ] 每个数字能在台账指到行；全文搜一遍禁用清单，命中即改
- [ ] 政策章未按时间罗列；建议章未替下游定案
- [ ] 取证局限写了具体检索式与日期，不是「多方查找未果」
- [ ] 示例一律中性化，无具体项目名
