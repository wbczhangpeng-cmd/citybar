# 检索式与信源白名单

本文件解决「去哪找、怎么搜、找到怎么判真假」。**它是本专家的入口层：入口找错，后面全白做。**

---

## 一、政策四层入口

政策必须按层级找全，缺一层就不能写「政策环境」。每层都有固定入口，别用泛搜索代替。

| 层 | 入口 | 检索路径 | 主要收什么 |
|---|---|---|---|
| 中央·国务院 | `www.gov.cn/zhengce/` | 政策 → **国务院政策文件库**（按机关、主题、年份、文种筛选） | 国发、国办发、国函、国务院令 |
| 中央·部委 | `www.mct.gov.cn`（文旅）、`www.ndrc.gov.cn`（发改）、`www.mnr.gov.cn`（自然资源）；住建、文物、林草同理 | 「政务公开／政策法规／政策解读」+ 站内搜索 | 部委规范性文件、行业标准、名单 |
| 省 | `wlt.<省简称>.gov.cn`（文旅厅）、`fgw.<省简称>.gov.cn`（发改）、`zrzyt.<省简称>.gov.cn`（自然资源厅） | 「政策文件」「规划计划」「信息公开目录」 | 省政府办公厅文件、省厅实施细则 |
| 市 | `<市拼音>.gov.cn` → 政务公开 → 政策文件 | 市政府文件库 + 各部门子站 | 市府发、市府办发、任务分解表 |
| 法规本体 | `flk.npc.gov.cn` | 直接检索法名 | 法律、行政法规、地方性法规 |

### 按项目类型换主管部门（先定类型，再定查谁的文）

| 项目类型 | 国家层面主管部门 | 省级对应厅局 | 这类项目最该盯的政策 |
|---|---|---|---|
| 文旅／景区／度假区 | 文旅部、发改、林草、文物 | 文旅厅、发改、林草 | 文旅专项规划、A 级景区与度假区标准、用地与林地转用 |
| 住宅／房地产 | 住建部、自然资源 | 住建厅、自然资源厅 | 房地产调控、住宅设计规范、供地与预售、配建要求 |
| 商业综合体／商业街区 | 商务部、住建、自然资源 | 商务厅、住建、自然资源 | 商业网点规划、消防与人防、业态准入 |
| 城市更新／老旧改造 | 住建部、财政、自然资源 | 住建厅、财政、自然资源 | 更新专项规划、拆改留政策、资金与指标奖励 |
| 片区开发／新城 | 发改、自然资源、住建 | 发改、自然资源、住建 | 国土空间规划、成片开发方案、片区综合开发政策 |
| 产业园区／工业上楼 | 发改、工信、自然资源 | 发改、工信、自然资源 | 产业准入目录、M0 与工业用地政策、环评能评 |

**换类型就换部门，别拿文旅的路子查住宅。** 查错部门的直接后果是：政策看着不少，但全是类比项，一条也不构成约束。

**层级不能跳**：省级文件把国家文件的模糊处写死（比例、面积、审批权限），市级任务分解表才有时间和责任单位。只读国家文件会得出「原则上允许」，读完省市两级才知道「实际卡在哪」。

### site: 限定式写法

```
# 通用骨架
site:gov.cn <项目类型关键词> 专项规划 2023..2026
site:gov.cn filetype:pdf 控制性详细规划 批复
site:gov.cn <项目类型> 用地 审批 办法

# 按类型换关键词
文旅：site:gov.cn 文旅融合 全域旅游 度假区
住宅：site:gov.cn 住宅 供地 预售 配建
商业：site:gov.cn 商业网点 综合体 消防
更新：site:gov.cn 城市更新 拆改留 老旧小区
片区：site:gov.cn 成片开发 片区综合开发
园区：site:gov.cn 产业准入 M0 工业用地
```

- `site:gov.cn` 已含各级政府，不必逐层写
- `filetype:pdf` 专捞附件正文——**很多规划正文只在 PDF 里，网页只有一段通知**
- 搜不到就换入口：政府站内搜索 > 必应 `site:` > 百度 `site:`；都不中，记入《取证局限》

## 二、三类规划怎么找、怎么判

| 类型 | 去哪找 | 文号长相 | 找什么才算「拿到了」 |
|---|---|---|---|
| 五年规划（纲要） | 政府网「规划计划」；发改委托管 | 通常**无文号**，经人代会批准，标题含「第X个五年规划纲要」 | 批准日期 + 发布主体 + 涉本项目章节原文 |
| 专项规划 | 主管厅局站点「专项规划」；多为部门联合发文 | `X发改规划〔2024〕N号`、`X文旅发〔2023〕N号` | 印发文号 + 规划期 + 重点任务表 |
| 国土空间总体规划 | 市/县自然资源局「规划公示」；省级须省政府批复 | 批复件：`X政函〔2024〕N号` | **批复文 + 批复日期**（未批复的是草案，不能当约束） |
| 控制性详细规划 | 自然资源局「控规公示/批后公布」 | 批复件：`X府函〔2023〕N号` | 地块图则：用地性质、容积率、限高、绿地率、配套 |
| 修建性详细规划 | 项目所在地公示栏 | 无统一文号，多为「批前公示」 | 公示图 + 公示期（未过=未生效） |

### 现行有效性四查（缺一不可）

1. **查废止条款**：新文件末尾常写「此前规定与本通知不一致的，以本通知为准」「同时废止……」。翻到最后一页看。
2. **查有效期**：规范性文件常写「有效期 5 年」。过期即失效，哪怕没人宣布。
3. **查规划期**：规划期已结束的（如「十三五」专项规划），只能作**历史沿革**引用。
4. **查清理决定**：搜「<发文机关> 清理规范性文件的决定」，很多文件是被批量废止的，正文不写。

> 判不了就写 `〔现行有效性：待核〕` 并进《取证局限》。**不要默认「政府网上挂着就是有效」。**

## 三、统计口径对齐

统计年鉴（年度，滞后 12–18 个月，有分县区细分）、统计公报（次年 3–4 月，只有大数）、**行业主管部门口径**（最快，但**自成一套，与统计局不可直接比**）三者不可混用。行业口径随类型变：文旅→文旅局（游客量、过夜率）／商业→商务局（社零、客流）／住宅→住建与房管（成交、去化、房价）／更新→住建（改造面积、户数）。

### 对齐三原则

1. **同年同口径优先**：跨年比较先换算到同一口径，换不了就在表下注明「口径不同，不作增速计算」。
2. **范围写清**：全域旅游人次 ≠ 购票入园人次；旅游总收入 ≠ 旅游综合收入；常住人口 ≠ 户籍人口。
3. **断点要标**：区划调整、口径修订、疫情年份，在数据行后加注 `〔口径断点：YYYY 年，前后不可直接比〕`。

### 高频陷阱对照

| 表述 | 常见错法 | 正确做法 |
|---|---|---|
| 「年接待游客 X 万人次」 | 拿文旅局数当统计局数 | 写明发布机关与口径（全域/购票） |
| 「人均消费 Z 元」 | 旅游总收入 ÷ 全域人次，说成「游客人均花费」 | 口径闭环：分子分母同范围 |

## 四、案例检索

### 关键词组合（出圈案例靠这几组捞）

```
<品类> 开业 首月 客流 万
<品类> 出圈 排队 限流
<品类> 爆红 小红书 抖音 打卡
<品类> 项目 停业 亏损 破产 重整
<品类> 二次消费 占比 复游
<品类> 获评 国家级 示范 名单
```

- 前四组捞成功案例，**「停业/亏损/破产/重整/流拍」必须单独跑一次**——失败案例不能靠回忆凑
- 抓到线索后回到一手：官网公告、政府新闻发布、上市公司年报、榜单原始页

### 平台热度榜在哪看

| 平台 | 入口 | 能拿到 | 不能拿来做什么 |
|---|---|---|---|
| 抖音 | 同城页「景点/游玩榜」「团购热销榜」 | 排名、在榜周数 | 折算客流 |
| 大众点评/美团 | 「必玩榜」「景点人气榜」 | 排名、点评量级、评分 | 判断经营质量 |
| 携程 | 「口碑榜」「景点热搜」 | 排名、点评量 | 反推营收 |
| 小红书 | 话题页浏览量、笔记数 | 热度量级 | 折算人次 |
| 微信指数 | `index.weixin.qq.com` | 热度曲线 | 作绝对量比较 |

> 榜单统一按 **B 级·仅作热度参照** 记账：`〔B 级，仅热度参照〕某项目在抖音同城景点榜连续在榜 N 周（2025-08 截取），此数据不用于客流测算。`

## 五、信源白名单

| 域名/来源 | 级别 | 用途 | 局限 |
|---|---|---|---|
| `stats.gov.cn`、省市统计局 | A | 年鉴、公报、普查 | 滞后、无细分到项目 |
| `gov.cn` 政策文件库 | A | 国发/国办发原文 | 附件常缺失，需回部门站找 |
| `flk.npc.gov.cn` | A | 法律、行政法规现行状态 | 不含部门规范性文件 |
| 部委站点（mct/mnr/mohurd/ncha） | A | 部委文件、行业标准、名单 | 栏目改版频繁，旧文常下线 |
| 省市厅局站点 | A | 实施细则、任务分解、批复 | 公开程度参差 |
| 政府新闻办发布会实录 | A | 开工/开业/投资额口径 | 宣传口径，投资额常含土地 |
| 上市公司年报/招股书 | B | 营收、客流、毛利率、坪效 | 仅上市主体，项目级披露少 |
| OTA 票价与点评量 | B | 票价、开放时间、热度量级 | 不用于客流测算；超三年仅作趋势 |
| 产权交易所/司法拍卖 | B | 真实成交价、流拍 | 样本少，多为一二线 |
| 主流媒体调查报道、券商/咨询研报 | C | 事件与争议、行业趋势 | 须两源互证；研报结论倾向乐观 |
| 专业公众号、地方自媒体 | C | 线索（不直接引结论） | 洗稿多，必须回到一手 |
| 百科、问答、AI 摘要 | **黑名单** | 仅作线索 | 不得引用；无链接「数据显示」同理 |

## 六、外文信源

非中文材料一律三件齐全，缺一件不用：

```
〔原文〕"...occupancy rate reached 62% in 2024..."（页码/段落）
〔译句〕2024 年入住率达 62%。
〔链接〕https://...（访问日期 2026-10-27）
```

优先机构原始页（UN Tourism、OECD、各国统计局），不引二手编译；单位与财年差异必须注明；原文用词模糊（如 `significant`）保留原文并标 `〔原文模糊，无法量化〕`。
