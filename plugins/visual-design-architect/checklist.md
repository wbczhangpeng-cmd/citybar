# 立象 · 自检清单

交付前逐条过。任何一条不过，就不算完成。

## 一、第一原则（最容易被违反的）

- [ ] 全文搜"大气 / 简洁 / 高级 / 灵动 / 呼吸感 / 层次分明 / 视觉冲击力 / 国际化 / 科技感"——**命中即改**
- [ ] 每个视觉选择都有理由，不只是给了一个值
- [ ] 破掉默认规则的地方都写了「此处破例：因为 X，代价是 Y」

## 二、设计令牌

- [ ] 五个色彩角色齐全（底色/主色/辅色/强调色/警示色），每个都有 HEX、用途、**面积占比上限**
- [ ] 中性色 ≥4 阶，正文对比度 ≥4.5:1
- [ ] 字号只用 7 级阶梯，每级有行高与字重，**无中间值**
- [ ] 间距只用 5 档（8/16/24/40/64）
- [ ] 栅格列数、边距、安全区已定
- [ ] 圆角、阴影、描边各自只有一套规定
- [ ] 图表序列色序已定（无彩虹配色）
- [ ] 图片裁切比例已定（全篇只一种）

## 三、页型库

- [ ] 页型总数 **≤15 种**
- [ ] 每种页型都定义了：沟通任务 / 分区比例 / 必填槽位 / 禁用
- [ ] 每种页型有 2–3 个变体
- [ ] 新增页型都经用户确认过（没有为单页造特例）

## 四、逐页蓝图

- [ ] 页码与析纲脚本严格一致，未重排
- [ ] 每页都标了页型 + 变体编号
- [ ] 每页都标了分区比例（取自令牌，无自创比例）
- [ ] 正文**引用淬言原文**，未擅自改写；填不下的标了"需回上游压缩至 X 字"
- [ ] 图表页写了：图型 + 系列数 + 轴设定 + 标签位置 + 色对应 + 数据来源项
- [ ] 每页指定了"第一眼"是什么（指不出来的页，说明没有主张）
- [ ] 关键页按"细"档、过渡与附录页按"简"档
- [ ] 脚注到具体文件/报告名 + 期间 + 口径，**没有"数据来源：项目组"这种写法**

## 五、样张

- [ ] 3–5 页，覆盖 ≥4 种页型
- [ ] 有一页按细档做到底
- [ ] 每页有"样张 · 非成品"角标
- [ ] 文字保持 `<text>` 未转曲
- [ ] 颜色与令牌逐项一致，字号行高与阶梯一致
- [ ] 图片全是占位并带五级标签
- [ ] PNG 已目视检查，无溢出、无字体回退错位
- [ ] 附了交付说明，明确三项待确认

## 六、图表与图元

- [ ] 每个图表标题是**结论句**，不是"XX 分析"
- [ ] 每个图表有**口径三件套**（单位·期间·口径定义）
- [ ] 每个图表有**数据源脚注**（无源不出图，宁可标"待补"）
- [ ] 涨红跌绿，未用西方惯例
- [ ] 色盲友好（不单靠红绿区分）
- [ ] 每张图挂了五级标签
- [ ] **AI 生成图未承载数据、未冒充实景、未冒充本项目效果图**
- [ ] 意向图在图上有"意向图"标注
- [ ] 图片需求清单每张都写了责任方（甲方/设计单位/需绘制/AI 生成），**无"待定"**

## 七、可编辑性

- [ ] 每种页型都声明了"可编辑边界"
- [ ] 文字全部原生文本框，未转曲未贴图
- [ ] 表格图表优先原生对象
- [ ] 复杂关系图用原生形状拼，**未整体截图**
- [ ] 图片只用于照片/意向图/图纸，未承载文字
- [ ] 已向用户说明"完全可编辑 vs 视觉精致"的取舍，并得到认可

## 八、风格提取（若本次涉及）

- [ ] 扫描前列了文件清单让用户确认范围
- [ ] 全量扫完一次给结果，没有逐个文件问
- [ ] 每份文件出了《风格指纹卡》
- [ ] 有一致度评分；低于 60 时说明了"这不是一种风格"
- [ ] **冲突时停下来问用户，没有自行融合**
- [ ] 有效页 ≥3 才有模板；不足标了"样本不足"并说明缺什么
- [ ] 模板带预览图
- [ ] 模板记了来源文件与版本号

## 九、契约与交接

- [ ] `design_spec` 首行有 schema 声明
- [ ] §I 写入了已确认的沟通契约，并有"**禁止 Strategist 重复发问**"声明
- [ ] 无图表引用时删掉了 §VII 整节（不留空标题）
- [ ] 没有残留占位符或示例值
- [ ] 交付附了"给落版的三句话"
- [ ] 事实包里**黑名单上的判断没有被做成重点版面**
- [ ] 页型分配表已附，占比落在健康区间（或已说明为何偏离）

## 十、最后一遍

- [ ] 通读自己的产出，像用户一样读一遍：**能不能照着排出来？**
- [ ] 找出你自己也不确定的三个地方，主动标出来请用户确认——**不要藏**
