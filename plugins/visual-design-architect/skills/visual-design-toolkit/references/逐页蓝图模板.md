# 逐页蓝图模板

蓝图是你交给下游的"施工图"。判断标准只有一条：**换一个完全没参与过讨论的人，照你的蓝图能不能排出这页。**

## 一、字段定义

| 字段 | 必须写到什么程度 |
|---|---|
| 页码 | 与析纲脚本严格一致，不许重排 |
| 页型 | 取自 15 种页型之一 + 变体编号（如"论点支持页·变体①左文右图"） |
| 分区与比例 | 用令牌里的分区比例（62/38、50/50、33/33/33、100、25/75）；标注每块在画布上的边距 |
| 各分区填什么 | **引用淬言润色稿的原文**，不要改写、不要概括。填不下就标"需回上游压缩至 X 字" |
| 图表形态与数据映射 | 图表类型 + 系列数 + 轴设定 + 标签位置 + 用哪几个令牌色对应哪个系列 + 数据来自事实包哪一项 |
| 强调层级 | 明确哪一个是"第一眼"、哪一个是"第二眼"，其余为背景层 |
| 留白与视觉重心 | 重心在版面的哪个方位；哪块必须留白、为什么 |
| 出处脚注 | 数据源 + 期间 + 口径；无来源标"待补"，不许留空 |

## 二、细档范例（关键页照此写）

```
页码：12
页型：数据图表页·变体②（主图+右侧结论栏）
分区：标题区 顶部 140px（含 1px 分隔线）；主体 62/38；页脚 48px
各分区：
  标题区 ——「目标年客流须达现状 2.4 倍，现有供给撑不住」（淬言 P12 原文，22 字）
  左 62% —— 图表区
  右 38% —— 1 句大字「2.4 倍是硬门槛」+ 3 条支撑
            （① 现状 38 万人次/年 ② 目标 92 万人次/年 ③ 区域年增速仅 6%）
图表形态：分组柱状图，2 组（现状 / 目标）× 1 系列；
  Y 轴 0 起，上限 100，单位「万人次」标注于轴右下；
  数据标签外置靠柱顶，14px，数值 38 / 92；
  网格线仅水平、中性第三阶、透明度 10%；
  现状柱 #1F3A34（主色），目标柱 #C8A46A（辅色）；
  关键倍数「2.4×」用强调色 #B4472E 标于两柱之间的括号线上；
  无图例（两组已直接标注）
强调层级：第一眼 = 标题的「2.4 倍」；第二眼 = 右侧大字「2.4 倍是硬门槛」；背景层 = 柱体与网格
留白与重心：重心在左上 60% 区域；右侧结论栏上下各留 XL(64) 的空白，不填满
出处脚注：现状客流据 XX 年报（2025）；目标值据本项目测算（口径：年入园人次，不含二次入园）
```

## 三、简档范例（过渡页与附录页）

```
页码：13
页型：论点支持页·变体③（三列并置）
分区：标题区 140px；主体 33/33/33，列间距 M(24)；页脚 48px
标题：「三条供给缺口同时存在」（10 字）
三列：① 住宿缺口——床位数不足目标客流的 40%
      ② 夜间业态缺口——18 点后营业占比仅 12%
      ③ 停留时长缺口——人均停留 0.6 天，区域均值 1.3 天
强调层级：三个小标题为第一眼，正文为第二眼
留白：三列各自顶部留 S(16)，不设色块底
出处：待补（需甲方提供床位数与营业时间统计）
```

## 四、分级规则

| 页面 | 档位 | 理由 |
|---|---|---|
| 执行摘要、定位页、收益测算、投资平衡、结论页 | **细** | 这几页错一处，全篇说服力崩 |
| 主要论点页、数据图表页、矩阵页 | **细** | 主力页，占篇幅最多 |
| 章节扉页、目录、目录式过渡 | 简 | 结构固定，无判断 |
| 附录页 | 简 | 只交代表名与口径 |
| 图版页 | 中 | 需写明每张图的标签与裁切比例，但不必写到像素 |
| 技术图纸页 | 极简 | 只有标题文本框 |

## 五、常见错误

| 错误 | 症状 | 改法 |
|---|---|---|
| 只写意图不写形态 | "用柱状图展示客群占比" | 补：几组几系列、轴怎么设、色怎么对、标签在哪 |
| 改写上游文案 | 蓝图里的句子与淬言原稿不一致 | 一律引用原文；填不下就标"需回上游压缩" |
| 空白画布 | "此处配图" | 必须写清图的五级标签、内容要点、责任方 |
| 强调层级缺位 | 没写"第一眼是什么" | 每页必须指定一个第一眼；指定不了说明这页没有主张 |
| 脚注写"数据来源：项目组" | 等于没写 | 必须到具体文件/报告名 + 期间 + 口径 |
| 蓝图里出现新数据 | 出现事实包里没有的数字 | 立即停，回验筹核实；不许在视觉环节造数 |

## 六、批量交付格式

按章交，每章一个块：

```
## 第 N 章 · 章节名（共 X 页）
- 本章页型使用：论点支持页×4、数据图表页×2、矩阵模型页×1
- 新增页型/图元：无

### P23 …（细档）
### P24 …（细档）
### P25 …（简档）
```

**每章必须报"有没有新增页型或新增图元"**。新增必须经用户确认，否则页型会失控。
