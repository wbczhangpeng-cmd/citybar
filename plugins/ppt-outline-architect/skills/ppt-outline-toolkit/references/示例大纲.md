- **核心结论句**：—
- **正文要点**：项目名、副标题、汇报单位、日期
- **表达方式**：全幅主视觉——滨水街区黄昏鸟瞰效果图（意向图，来源：视觉环节补），左下角压标题文字；构图 2:1 横版。
- **文字量级**：标题 1 行 + 副标题 1 行 + 单位/日期 1 行

- **页面类型**：内容页

### P03 · 摘要（先给结论）
- **章节归属**：摘要
- **页面标题 / 副标题**：一句话结论：做"城市近郊微度假 + 在地文化体验"的滨水目的地
- **页面意图**：让评审在 1 分钟内抓住全案主张。
- **核心结论句**：为本地家庭与周边游客，提供"半天到两天"的滨水文化微度假。
- **正文要点**：
  1. 定位：近郊微度假 + 在地文化体验
  2. 客群：本地家庭 / 周边城市周末客群
  3. 策略：文化 IP 驱动 + 滨水场景 + 轻餐饮零售复合
  4. 落地：分两期，先启动核心区
- **表达方式**：左侧大字结论 + 右侧 4 个图标要点（图标示意，视觉环节做）；底部一条"认知→定位→策划"流程条。
- **文字量级**：大字 1 句（≤20 字）+ 4 条要点（每条 ≤18 字）
- **演讲备注**：先抛结论，后续章节再展开论证；过渡句"为什么是这个定位，先看家底"。
- **素材引用**：筑策报告 Part2 一句话定位
- **初步文案**：我们建议把这个滨水街区，做成城市近郊的微度假目的地，主打在地文化体验。
- **页面类型**：内容页

### P18 · 一句话定位
- **章节归属**：第二章 / 第一节
- **页面标题 / 副标题**：为谁 · 提供什么 · 凭什么
- **页面意图**：把定位收敛成一句可记忆的话。
- **核心结论句**：为本地家庭与周边周末客群，提供滨水文化微度假，凭"在地文化 IP + 滨水场景"形成差异。
- **正文要点**：
  1. 为谁：本地家庭 / 周边 2 小时圈周末客群
  2. 提供什么：半天–两天滨水文化微度假
  3. 凭什么：在地文化 IP + 滨水生态场景
- **表达方式**：居中一句定位陈述（大字），下方三栏"为谁 / 提供什么 / 凭什么"；用关系图（三角）强化三者关系。
- **文字量级**：定位句 ≤40 字；三栏各 ≤15 字
- **演讲备注**：逐词解释定位句，强调"差异在文化 + 滨水"。
- **素材引用**：筑策报告 Part2 定位矩阵
- **初步文案**：我们为本地家庭和周边周末客群，提供半天到两天的滨水文化微度假，靠在地文化和滨水场景做出不一样。
- **页面类型**：内容页

### P29 · 总平面与功能分区（图版页）

- **文字量级**：标题 + 3 条图注
- **演讲备注**：指图讲"一核两带三组团"的空间逻辑。
