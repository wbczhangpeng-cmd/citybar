# 交付前自检清单

逐项打勾，全部通过方可交付。

## 0. 叙事（**先过这组，不过就别看后面了**）

这是本组最容易糊弄过去的一组。**四项全过才算大纲成立；只过其中一项，说明你在拆页。**

- [ ] **总结论已定且用户确认**：一句话、≤40 字、是判断句不是描述句，写在大纲最前面
- [ ] **标题竖读**：把 P01–Pnn 的页面标题按顺序连起来读，读出来是**一段论证**而不是一份目录
- [ ] **观点竖读**：把每页「核心观点」连起来读，能读出一条完整的推理链，没有重复、没有并列罗列
- [ ] **删页测试**：随机想删三页，**删了之后有页失去支撑的才有存在理由**；删了没影响的说明是凑数
- [ ] **每页一问题**：「本页唯一要解决的问题」只有一个问号；两个以上 = 拆页
- [ ] **推进关系**：相邻两页必须构成递进 / 转折 / 递交之一；出现并列、重复、无关 = 重排
- [ ] **叙事链表已填**（模板 §0.5）：逐页填了叙事动作 + 与前页关系

> **一句话判据**：把你 55 个页面标题连起来读，读不出一个结论 —— 那这份大纲就算有 60 页也是失败的。

## 0.5 图片（**文旅类汇报的生死线，先过这组**）

- [ ] **每页都填了「本页图片需求」**，且落到 `P / S / O` 三档之一。**写「可配图」＝ 没判**
- [ ] **P 档页数 ≥ 总页数 35%**（文旅 / 商业综合体 / 景区规划类通用底线）。低于 35% → 这份汇报是资料汇编，不是说服材料
- [ ] **现状诊断页全是 P 档** —— 不展示现状就谈问题，是无据的判断
- [ ] **文化载体页（器物 / 遗址 / 专名实物）都是 P 或 S 档**，不是 O
- [ ] **对标案例页有图** —— 没有对方的现场图，"可比性"是空的
- [ ] **图版页 / 动线图 / 总平面 标的是「分析图·自绘」，不是「待甲方」**
- [ ] **可自行生成的数量已数出来**（分析图 + 意向图），且不为 0
- [ ] 图文配比表已填全（模板 §2.5），三行汇总已写
- [ ] 需要甲方提供的，**已单独列出成索取清单**（不是混在缺口里等落版发现）

> **真实事故**：一份 58 页文旅汇报，**全篇 0 张图片**。
> 图片清单不是没有（有 17 项），但几乎全标"待甲方提供"，而其中动线图、矩阵图、面积分析图
> 本来都是能自己画的。**一律标"待甲方"，等于把能做的事也挂起。**
> 结果甲方看到的是一份纯文字的可行性研究报告。

> **一句话判据**：把这份 PPT 上的字全遮住，只看图 —— 你能看出这是个什么项目、现状什么样、
> 将来会变成什么样吗？**看不出，就是图片不够。**

## A. 结构
- [ ] 前置三页齐全：封面 / 目录 / 摘要(总结)
- [ ] 主体章节来自与用户确认过的候选，未擅自写死
- [ ] 层级清晰：一级 / 二级 / 三级语义对应
- [ ] 命名风格与用户选择一致（默认常规中文）
- [ ] 目录结构 + 页数分配表已出并确认

## B. 规模与内容
- [ ] 总页数 ≥40（有技术图纸则更多），与时长匹配
- [ ] 每页字段齐全（页码 / 章节 / 标题+副标题 / **唯一要解决的问题** / 核心观点 / **数据或图表** / **画面建议** / 要点 / 文字量级 / **口播重点** / 素材引用 / **初步文案**）
- [ ] 「数据或图表」具体到「用哪个数、画成什么图」；无数时写明用关系图/示意，**不写"用数据支撑"这类空话**
- [ ] 「画面建议」给立象可直接用，没有形容词（写了"大气/现代感"= 不合格）
- [ ] 每页"页面意图"一句话说清，不空泛
- [ ] 正文要点 3–5 条，短句、可读
- [ ] 初步文案是"成句半成稿"，不是关键词堆砌

## C. 表达方式
- [ ] 每页表达方式写到"下游 AI 能照着画"（主视觉 / 图表类型 / 构图分区 / 数据来源）
- [ ] 未强行套用固定表达分类，但描述无歧义
- [ ] 图版页只排标题、页面留空，并写明"以图为主"及所需图纸内容与来源

## D. 表格与受众
- [ ] 8 张表均有"1 主承载页 + 附录附表"
- [ ] 正文用可视化简化，明细进附录
- [ ] 多受众已取并集，优先级排序正确，摘要页体现

## D2. 初步文案纯度（**真实踩过的坑，重点查**）

- [ ] **每页「初步文案」都是能直接粘进 PPT 文本框的成段文字**
- [ ] 文案字段里**没有**施工指令词：`已删` / `已改` / `待核` / `页面类型` / `本页须` / `注意` / `禁用`
- [ ] 没有把「要点罗列」当文案交（如果一页的文案是 4 个短条目，那不是成段文字）
- [ ] 骨架页已逐页列举豁免理由（只允许：技术图纸页 / 附录索引页），**没列举的骨架页一律判不合格**

> **真实事故**：一份 55 页大纲，29 页的「初步文案」字段装的是「全篇禁用提升/优化」这类施工备忘，
> 甚至把「页面类型」字段串了进去。下游只能照搬，最后 8 页骨架文案原样进了定稿。
> **判据：把这段字粘进 PPT，需要再补写或再删备注吗？需要就不合格。**

## E. 交接与真实性
- [ ] 末尾附"交接说明 + 字段契约"（本稿状态 / 锁定章节 / 待补项 / 下游动作）
- [ ] 所有数字、案例、政策均来自用户或报告，未编造
- [ ] 缺失信息已标注"待补 / 待确认"，未硬填
- [ ] 输出语言与用户一致
