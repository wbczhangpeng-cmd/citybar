| 序 | 页 | 页面标题 | 叙事动作 | 与前页的关系 | 核心观点（一句判断） |
|---|---|---|---|---|---|
| 1 | P05 | （填标题） | 立靶 | 开篇 | （填判断） |
| 2 | P06 | | 归因 | 递进：因为上一页成立 | |
| 3 | P07 | | 定点 | 转折：但只有三处能改 | |

- **叙事动作**：立靶 / 归因 / 定点 / 给路 / 兜底 / 支撑 / 附录
- **与前页的关系**：递进 / 转折 / 递交

**这张表的作用**：55 页靠人逐页看是看不出拆页的，竖排连读一眼就看出来了。

## 0.6 幕式结构表（交付前必填 —— 用来证明「这不是文档目录」）

**每一段都要有三件套 + 一个字。缺一件，这一段就还是文档标签。**

| 幕 | 幕名（四字·四字） | 对句（八字） | 一字定性 | 释义（这段的任务，≤25 字） | 页范围 |

| 序幕 | 开篇 · 传承 | 一枚凭证，邀君入城 | 引 | 未入场先领身份，未开讲先立情境 | P01–P04 |

| 二 | | | | | |
| 三 | | | | | |
| 四 | | | | | |
| 五 | | | | | |
| 尾声 | | | | | |

**四条判据**：
- 幕名里不许出现「分析 / 概况 / 体系 / 路径 / 措施」——那是文档语言
- 一字定性**不许重复**（两段同字 = 它们是同一段，合并）
- 竖着念幕名，应该像一台戏的目录；像章节列表 → 重起
- 写不出一字定性 → 这一段性质没想清，回去重想，**不要硬凑一个字**

## 0.7 情绪曲线表（交付前必填 —— 45 分钟的节奏是设计出来的）

逐页一行，全部页面都要出现。五档：**起 / 沉 / 扬 / 放 / 收**。

| 页 | 情绪档 | 这一段在做什么 | 给谁喘息 / 什么时候让人掏钱 |
|---|---|---|---|
| P05 | 起 | 让他承认问题真实存在 | — |
| P12 | 沉 | 冷静下来看结构 | **全篇第一次喘息** |
| P16 | 扬 | 给一个能立住的理由 | — |
| P33 | 放 | 看见可能性，开始算钱 | **转化率最高的一段** |
| P54 | 收 | 给行动，不给幻想 | — |

**四条硬规则**（跑 `check_outline_narrative.py` 核，不靠人看）：
1. 相邻三页不得同档
2. 全篇至少一次「沉」一次「放」—— 没有"沉"是不给喘息；没有"放"是没有让人松下来掏钱的段落
3. 「扬」连续不超过 3 页
4. **最后一页必须是「收」**，不是「扬」

**一条经验**：产品页、收益页要排在「扬」之后，不要排在「扬」当中——**最松弛的那一段，转化率最高。**

## 2.5 图文配比表（交付前必填 —— 用来自查"这到底是不是一份以图论证的汇报"）

逐页一行，全部页面都要出现：

| 页 | P/S/O | 图承担什么 | 图源标签 | 责任方 | 现在能拿到吗 | 拿不到怎么办 |
|---|---|---|---|---|---|---|
| P06 | **P** | 闲置广场实景 | 实景照片 | 甲方 | ❌ | **发函索取；拿不到则本页不许定稿** |
| P14 | **P** | 渠系走向示意 | 分析图 | 自绘 | ✅ | — |
| P26 | **P** | 强制动线图 | 分析图 | 自绘 | ✅ | — |
| P31 | S | 场地现状 | 实景照片 | 甲方 | ⚠️ 待实测 | 占位 + 进缺口清单 |
| P45 | O | 氛围底图 | 生成装饰图 | AI | ✅ | 可省 |

**三行汇总必须写在表下面**：
- P 档 __ 页，其中「现在拿不到」__ 页 → **这几页是交付的前置条件**
- 可自行生成 __ 张（分析图 + 意向图）→ **落版的活，不是甲方的活**
- 需外部提供 __ 张 → **进索取清单，出大纲时就要发出去，不是等到落版才发现**

> **为什么要在这一步就分清"能不能自己弄"**：58 页 0 图的那份稿子，
> 图片清单里 17 项几乎全标了"待甲方提供"，而其中**动线图、矩阵图、面积分析图本来都是能自己画的**。
> 一律标"待甲方"，等于把能做的事也挂起，最后整份汇报就空了。
