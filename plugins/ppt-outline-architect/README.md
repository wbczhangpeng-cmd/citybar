# 析纲 · 策划方案转 PPT 大纲专家

把「项目策划与定位报告」拆成结构化、可执行的 PPT 汇报大纲与逐页脚本，作为后续文字润色、视觉设计与 PPT 制作的**单一事实源**。

## 类型

Agent 型（单个 AI 专家）

## 在专家组中的位置

`1 总体策划定位(筑策) → 2 商业逻辑审查 → ③ 出PPT框架(析纲) → 4 文字润色去AI味 → 5 视觉表达设计 → 6 PPT初稿生成 → 7 美化与表达优化 → 8 逐页精修 → 9 完稿`（总编排最后建）

## 功能

- **读料**：吃筑策三段式报告 + 8 张关键表 + 审查意见 + 补充材料，先列「已获取 / 待补」清单。
- **问参**：先问受众（多选）与时长，默认政府/甲方立项汇报约 30 分钟。
- **出结构**：前置固定（封面/目录/摘要），主体章节生成 2–3 套候选供选，锁定后展开。
- **逐页脚本**：每页给出意图、结论句、要点、表达方式、文字量级、演讲备注、素材引用、初步文案。
- **多风格命名**：常规中文 / 国际化英文 / 国风 / 文艺 / 商务极简 / 政企汇报，可整套或逐级切换。
- **规模与图纸**：默认 ≥40 页；技术图纸页只排标题、留空并注明"以图为主"。
- **表格落页**：8 张表正文可视化简化、附录全量，每表 1 主承载页 + 附表。
- **交接契约**：输出带稳定字段与页编号，附交接说明，供下游与总编排对接。

## 使用示例

- 这是筑策出的项目策划报告，帮我拆成结构化的 PPT 汇报大纲和逐页脚本。
- 我要给政府评审做 30 分钟汇报，帮我把方案大纲按汇报叙事重排。
- 把大纲章节改成国风命名，并写清每页的图表与配图建议。

## 安装 / 注册

将专家包目录放到专家目录下：

```
C:\Users\PC\.workbuddy\plugins\marketplaces\my-experts\plugins\ppt-outline-architect\
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
python3 scripts/package_expert.py <expert-dir>
```
