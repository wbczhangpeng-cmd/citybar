# 交付前自检清单

每次交付《审查报告》《问题清单》《可信事实包》《复审结论》前，逐条过一遍。**任一红项未过，不得交付。**

---

## 一、反幻觉红线（最高优先级）

- [ ] 结论中出现的**每一个数字**都有 `出处 + 获取时间 + 原文片段`
- [ ] 没有任何"数据显示/据测算/业内普遍认为"而无出处的表述
- [ ] 没有把记忆里的数字、联想的报告名、想当然的机构名写进报告
- [ ] 没有用 UGC（点评数、播放量）反推绝对客流或营收
- [ ] 没有把 D 级推断（含"行业惯例"）作为 P0 判定或整体结论的唯一支撑
- [ ] 没有把委托方提供的材料（S 级）当作经外部验证的数据
- [ ] 查不到的项目**明确写成"证据不足，暂不判定"**，并进了《待补数据清单》
- [ ] 《取证局限说明》已写，且列出了"该查而未查到"的项
- [ ] 数字单位、口径（购票人次/全域人次、可租面积/建筑面积）全文一致

## 二、流程合规

- [ ] 第 1 段《审查方案》已提交并经用户确认（**未确认就取证=越流程**）
- [ ] 已声明使用了哪册清单
- [ ] 疑似问题按批（5–8 条）提交，且**每条都拿到用户回执**
- [ ] 正式清单里**没有未经确认的条目**
- [ ] 被"驳回"的条目没有变相复活
- [ ] 被"降级/改档"的条目已按用户裁定改写
- [ ] 未提供的材料部分已声明"不审"，未判为缺失

## 三、分析完整性

- [ ] 三层审查（闭环/自洽/市场）都有独立结论
- [ ] 两项专项（定位成立性/业态合理性）都已覆盖
- [ ] 七环链条逐环给了"有数/无据"的判断
- [ ] 十二项勾稽做了，矛盾台账已出
- [ ] 对标 3–5 个样本，含**至少 1 个反向样本**
- [ ] 每个关键假设都算了**偏离幅度**，不是只写"偏高"
- [ ] 五维分级已给，**没有打综合分**
- [ ] 整体结论之后有《整体修正路径》，并回答了"改完能否闭合"

## 四、修改建议的质量

- [ ] 每条建议都是 `改哪个假设 → 改成什么量级 → 依据什么 → 接上哪一环`
- [ ] **没有出现**"建议进一步论证""建议加强调研""需结合实际情况判断"这类空话
- [ ] 需要补数据的，已明确列进《待补数据清单》（而不是含糊写"再核实"）

## 五、边界

- [ ] 未代写方案、未直接改稿
- [ ] 专业合规（消防/环评/结构/文保）只提示、未下结论
- [ ] 未替筑策做创意与定位决策
- [ ] 未对项目下绝对化结论（"必然失败"）

## 六、给析纲的事实包

- [ ] 结论摘要可直接进汇报（已过滤掉未确认条目）
- [ ] 已核验数据都带出处
- [ ] **已被否定的假设黑名单**已列出，且写明"若必须提及应如何表述"
- [ ] 已标注建议主动披露的风险（2–3 条）
