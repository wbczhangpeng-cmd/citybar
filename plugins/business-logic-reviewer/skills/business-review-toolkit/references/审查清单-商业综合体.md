# 审查清单 · 商业综合体册

适用于：购物中心、社区商业、街区型商业、奥莱、专业市场改造。
与文旅册最大的差别：**核心不是客流，而是租金、坪效与招商可实现性**——客流再多，租金收不上来一样不成立。

---

## A. 市场与商圈（SY-A）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| SY-A1 | 商圈界定 | 商圈半径随意（说 3 公里却按 10 公里人口算） | P0 |
| SY-A2 | 商圈人口与消费力 | 用行政区人口代替商圈人口；未看人均可支配收入与社零增速 | P1 |
| SY-A3 | 竞品供给 | 未统计同商圈存量与未来 2–3 年新增供应 | P0 |
| SY-A4 | 分流强度 | 只列竞品名单，不评估分流 | P1 |
| SY-A5 | 客群结构 | 未区分目的性消费/随机消费/社区刚需 | P1 |
| SY-A6 | 消费外流 | 未考虑本地消费外流（去更高能级城市消费） | P2 |

## B. 定位与业态组合（SY-B）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| SY-B1 | 定位与商圈能级匹配 | 县域商圈做重奢/首店经济 | P1 |
| SY-B2 | 主力店依赖度 | 单店面积占比过高，主力店一走全盘崩 | P1 |
| SY-B3 | 业态配比 | 餐饮/零售/体验/服务比例失衡（餐饮过高毛利低、零售过高无人流） | P1 |
| SY-B4 | 与竞品差异 | 品牌组合与竞品高度重合 | P1 |
| SY-B5 | 首店与网红依赖 | 大量依赖首店/网红品牌，未评估其留存率与租金承受力 | P2 |
| SY-B6 | 动线与层高 | 冷区面积过大、高层到达性差却按平均租金测算 | P1 |
| SY-B7 | 体验业态占比 | 体验业态面积大但坪效低，与租金目标冲突 | P1 |

## C. 招商与租金（SY-C）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| SY-C1 | 租金水平 | 租金单价偏离同城同类挂牌价，无解释 | P0 |
| SY-C2 | 出租率假设 | 开业即按 95% 出租率；无爬坡期 | P0 |
| SY-C3 | 免租期与装修补贴 | 未计免租期、装补、招商佣金 | P1 |
| SY-C4 | 租金递增条款 | 按固定年递增测算，未考虑换租与空置 | P1 |
| SY-C5 | 抽成租金 | 只取固定租金与抽成中的较高值，不考虑淡季取低 | P1 |
| SY-C6 | 招商可实现性 | 目标品牌在该城市无拓店计划；无备选品牌库 | P1 |
| SY-C7 | 租户结构风险 | 单一租户租金占比过高 | P2 |
| SY-C8 | 物管费与能耗费 | 未说明是否覆盖运营成本 | P1 |

## D. 收益与成本（SY-D）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| SY-D1 | 坪效口径 | 用建筑面积算坪效（应用可租面积） | P1 |
| SY-D2 | 营业额与租金的关系 | 抽成租金测算的营业额无依据 | P1 |
| SY-D3 | 运营成本完整性 | 缺人力、能耗、推广、维修、保险、税 | P0 |
| SY-D4 | 开业爬坡 | 无 1–3 年爬坡曲线 | P0 |
| SY-D5 | 多经收入 | 广告、场地、停车等收入是否计入、有无依据 | P2 |
| SY-D6 | 资本化退出 | 若按 REITs/整售退出，估值假设是否有市场支撑 | P1 |

## E. 投资与分期（SY-E）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| SY-E1 | 单位造价 | 与同类商业体造价对比 | P1 |
| SY-E2 | 投资口径 | 含不含土地、软装、开办、招商补贴 | P1 |
| SY-E3 | 回收期 | 与同类项目对比；口径是否一致 | P0 |
| SY-E4 | 分期与开业 | 分期开业导致动线断裂、整体体验受损 | P2 |
| SY-E5 | 资金成本 | 未计融资成本 | P1 |
| SY-E6 | 敏感性 | 无出租率与租金双下行情景 | P1 |
