# 审查框架

三层审查（闭环 / 自洽 / 市场）+ 两项专项（定位成立性 / 业态合理性）的操作手册。每层独立出结论，最后合成整体可信度。

> **通用原则**：本框架只提供**检查结构**与**推导公式**，不提供任何默认基准值。所有基准必须由 `证据标准与取证手册.md` 取证后填入；取不到就写"证据不足"。

---

## 一、闭环审查（这账能不能算过来）

### 1.1 七环链条

| 环 | 关键量 | 必须回答 |
|---|---|---|
| ① 客源总量 | 区域年游客量 / 常住人口 / 客源半径内人口 | 用的是什么口径？过境游还是过夜游？ |
| ② 可达客流 | 捕获率 = 本项目客流 ÷ 区域客源总量 | 捕获率依据什么？与同类项目比是否离谱？ |
| ③ 有效客流 | 停留时长、转化率、复访率、团散比 | 转化假设有依据吗？团客按什么结算？ |
| ④ 人均消费 | 门票 + 二消（餐饮/零售/体验/住宿） | 二消占比凭什么？对标谁？ |
| ⑤ 总收入 | 票务 + 二消 + 租金/分成 + 补贴 + 其他 | 各占比是多少？非经营性收入占多少？ |
| ⑥ 运营成本 | 人力 / 能耗 / 维护 / 营销 / 招商佣金 / 税 | 成本率（成本÷收入）是多少？对标谁？ |
| ⑦ 投资与回收 | 投资总额、EBITDA、静态回收期、IRR | 投资口径含不含土地、含不含财务费用？ |

### 1.2 每环三问

对每一环都问：**① 有没有算？② 怎么算的（依据+出处）？③ 与上一环、下一环的量级接不接得上？**

第三问是关键——**多数方案的断点不是"某一环算错"，而是"环与环之间数量级脱节"**：客流假设按 300 万人次做，但停车位、餐位、厕位、讲解员配置只按 30 万人次配；或者人均消费按 200 元算，但业态清单里连一个能卖出 200 元的消费点都没有。

### 1.3 断点信号（命中任一即深挖）

1. **收入 ≤ 运营成本**：正常经营永远无法自我维持 → 结构性问题
2. **回收期依赖非经营性收入**（地产销售、政府补贴、上级拨款）却未写实现路径 → 关键风险
3. **客流假设与现实承载不匹配**：无停车/无床位/无餐饮容量却承诺大客流
4. **人均消费无对应消费场景**：业态清单里找不到能支撑该客单价的品类
5. **增长率假设单调向上**：连续多年正增长却无市场趋势支撑
6. **成本项缺失**：只算建设不算运营，或只算人力不算能耗维护营销
7. **"后期靠…"句式**：把不闭合的环推给未来的二期、地产、政策、招商奇迹

### 1.4 闭环结论判据

- 七环全部有数、有据、量级相接 → `成立`
- 有环缺失但缺口有明确补法 → `有条件成立`
- 出现"收入 ≤ 运营成本"或"回收依赖无路径的外部输血" → `不成立`
- 关键环无任何可用证据 → `证据不足，暂不判定`

## 二、自洽审查（内部有没有打架）

**这是最容易拿到铁证的一层——纯机械核对，不需要外部数据，却能直接定性 P0/P1。审完自洽再审闭环，效率最高。**

### 2.1 十二项勾稽

| # | 勾稽 A | 勾稽 B | 冲突即问题 |
|---|---|---|---|
| 1 | 定位档次（高端/大众/普惠） | 业态客单价结构 | 高端定位配低客单业态 |
| 2 | 目标客群构成（本地/外地、团/散） | 收益测算的客群口径 | 说要本地复购，测算按外地一次性 |
| 3 | 功能配比表 | 总建筑面积 / 可租可营面积 | 加总不符、口径混用 |
| 4 | 业态面积配比表 | 功能配比表 | 两表分类与加总对不上 |
| 5 | 承诺客流量 | 停车位/床位/餐位/厕位/讲解员等承载 | 承载量支撑不了承诺客流 |
| 6 | 承诺客流量 | 员工编制与服务能力 | 服务能力不足 |
| 7 | 投资估算 | 单位造价（元/㎡）× 面积 | 投资与面积对不上量级 |
| 8 | 分期实施计划 | 投资节奏 / 开业时间 / 收益测算起始年 | 一边说三期五年建成，一边从第一年就测算全量收益 |
| 9 | 收益测算的增长率 | 区域市场趋势（外部） | 逆市场趋势假设 |
| 10 | 竞品对标结论 | 自身定位与规模 | 一边说竞品已饱和分流，一边说自己还能大幅分流 |
| 11 | 政策/规划依据 | 实际业态安排 | 用地或用房性质不支持该业态 |
| 12 | 同一数字的跨章引用 | 面积、投资、客流、营收、出租率 | 同一个数字在两章不一样 |

### 2.2 矛盾台账（必须落表）

`矛盾编号｜A 处（章节/表 + 原文）｜B 处（章节/表 + 原文）｜矛盾性质（量级不符/口径混用/结论互斥）｜我的建议档位`

矛盾台账**不依赖外部取证即可定性**，是报告里最硬的部分，优先呈现。

## 三、市场支撑审查（外部站不站得住）

### 3.1 四类支撑

| 类别 | 要查什么 | 典型 A/B 级来源 |
|---|---|---|
| **客源基础** | 区域年游客量及增速、过夜率、人均花费、停留天数、客源结构（本地/省内/省外、团散比）、季节性分布 | 统计年鉴、文旅局公报、政府工作报告、节假日文旅通报 |
| **竞品分流** | 同城/同区域同类项目数量、体量、票价、开业时间、热度、新增供给计划 | OTA 票价与点评、景区官网、新闻、规划公示 |
| **价格与消费能力** | 同类项目票价区间、二消品类价格带、当地人均可支配收入与消费水平 | OTA、统计公报 |
| **同类经营实况** | 真实客流、坪效、出租率、回本周期、失败案例的失败原因 | 上市公司年报/招股书、协会报告、司法拍卖与产权交易、公开采访 |

### 3.2 必做的三个结构分析

1. **人次 vs 收入结构**：区域旅游是"人次涨、收入不涨"还是"量价齐升"？前者意味着过境游为主，承接型项目要先解决"留下来"。
2. **淡旺季与现金流**：旺季几个月、淡季靠什么、现金流最低点在哪个月，测算有没有体现季节性。
3. **过境 vs 过夜**：过夜游客量才是二消与住宿的真实基础；用总游客量做二消测算是最常见的口径错误。

### 3.3 常见病灶

- 只用"区域客流大盘"做分子，不做捕获率论证
- 用"全国同类标杆"当本地基准（标杆只作上限参照）
- 引用竞品数据不注时间（三年前的客流当现在用）
- 把"政策利好"当"客流保证"

## 四、定位成立性审查（专项）

### 4.1 三问

1. **推导链是否连续**：从区位/场地/市场/客群的分析，能不能一步步推出这个定位？中间有没有"跳步"（分析说 A，定位却说 C，B 环缺失）？
2. **差异化是否真实**：这个定位竞争者能不能一句话复制？如果能，差异化是假的。
3. **可否落地**：定位能不能转化成空间、业态、产品与服务清单？落不下去的定位是口号。

### 4.2 常见病灶

| 病灶 | 表现 |
|---|---|
| 定位是愿望不是结论 | 通篇形容词（高端、国际、标杆、唯一），无可验证的取舍 |
| 定位与区位条件冲突 | 定位要求大客流，区位却是低可达性支线 |
| 定位覆盖过宽 | 一页里既要做亲子又要做康养又要做研学又要做夜经济，客群互斥 |
| 定位与体量不匹配 | 3 万㎡承载"国家级度假目的地"叙事 |
| 定位缺少"不做什么" | 没有取舍 = 没有定位 |

## 五、业态规划合理性审查（专项）

### 5.1 五问

1. **与客群匹配**：主力业态服务的是不是核心客群？边缘业态占了多大面积？
2. **与体量匹配**：业态数量与面积是否撑得起（业态过多→每个都做不深；过少→逛不住）
3. **与竞争格局匹配**：区域内已有什么、本项目补什么空位、还是重复建设
4. **招商可实现**：品牌有没有落位意愿？首店/主力店依赖度多高？备选有没有
5. **运营可承载**：人力、供应链、能耗、管理半径能不能支撑

### 5.2 组合结构分析（必做）

把业态分成三类并算面积占比：
- **引流业态**（拉人来的：核心吸引物、网红打卡、免费开放空间）
- **变现业态**（挣钱的：餐饮、零售、体验、住宿）
- **配套业态**（维持体验的：停车、卫生、导视、休憩）

判断：引流占比过低 → 来不了人；变现占比过低 → 来了不花钱；配套占比过低 → 体验崩、口碑差。**比例是否合理必须靠对标取证，不能凭感觉。**

### 5.3 客群结构配比检验

- **本地复购型** vs **外来一次性型**：两者的业态逻辑完全不同（前者要高频刚需+会员，后者要一次性高客单+强打卡）。方案里的业态与它声称的客群结构是否同一套逻辑？
- **团客 vs 散客**：团客靠返点与团餐，散客靠体验与零售，混着算必错。
