# 审查清单 · 片区开发册

适用于：新区起步区、城市组团、站城一体（TOD）、产城融合片区、滨水／沿山片区、跨地块综合开发。

与单项目册最大的差别：**核心不是某一个项目赚不赚钱，而是整个片区能不能自己转起来**——收入靠什么、支出压在哪、时序卡在哪一环。片区开发最常见的死法不是定位错，是**现金流断在第三年**。

---

## A. 片区定位与功能结构（PQ-A）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| PQ-A1 | 片区定位 | 功能什么都装（居住＋商业＋产业＋文旅），没有主功能 | P0 |
| PQ-A2 | 与上位规划一致 | 功能结构与法定规划、控规不符或未核对 | P0 |
| PQ-A3 | 与周边分工 | 未说明与相邻片区／新城的差异，重复布点 | P1 |
| PQ-A4 | 人口与就业支撑 | 只给人口规模目标，不给就业岗位来源与导入路径 | P0 |
| PQ-A5 | 功能配比 | 居住、产业、商业、公共服务用地比例无依据 | P1 |
| PQ-A6 | 开发强度 | 容积率与整体风貌、基础设施承载力脱节 | P1 |

## B. 用地与开发时序（PQ-B）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| PQ-B1 | 用地平衡 | 总用地与各类用地之和对不上；未扣道路与市政 | P0 |
| PQ-B2 | 分期边界 | 分期只按面积切，不按功能闭环切（首期没有配套就卖房） | P0 |
| PQ-B3 | 首期启动区 | 首期规模过大或过小；未说明首期凭什么能形成人气 | P0 |
| PQ-B4 | 拆迁与供地 | 拆迁量、供地节奏未与实际可交付土地挂钩 | P0 |
| PQ-B5 | 基础设施先行 | 道路、管网、场站的建成时间晚于地块开发 | P1 |
| PQ-B6 | 时序弹性 | 无"若某期延后"的应对；计划全按理想状态排 | P1 |

## C. 资金平衡与现金流（PQ-C）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| PQ-C1 | 平衡口径 | 只算土地出让收入，不算基础设施与公服投入 | P0 |
| PQ-C2 | 收入来源 | 收入结构单一（全靠卖地），无产业税收、运营收入 | P0 |
| PQ-C3 | 现金流曲线 | 无逐年现金流，只给总量平衡 | P0 |
| PQ-C4 | 峰值缺口 | 未识别哪一年缺口最大、缺口靠什么补 | P0 |
| PQ-C5 | 土地价格假设 | 出让价格按当前行情线性外推 5–10 年 | P1 |
| PQ-C6 | 融资结构 | 未说明资本金比例、融资成本、还款来源 | P1 |
| PQ-C7 | 政策性资金 | 专项债、中央预算内、城市更新基金等是否已考虑、条件是否具备 | P1 |

## D. 基础设施与公共服务（PQ-D）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| PQ-D1 | 市政承载力 | 给水、排水、电力、燃气、污水未做容量校核 | P1 |
| PQ-D2 | 交通组织 | 只画路网不做流量；对外通道未与市级规划对接 | P0 |
| PQ-D3 | 公服配套 | 学校、医院、文体按人口配建但未算运营主体与经费 | P1 |
| PQ-D4 | 生态与安全 | 洪涝、地灾、污染场地未排查即定功能 | P0 |
| PQ-D5 | 运营主体 | 建成后谁运营、钱从哪来，未明确 | P1 |

## E. 实施主体与政策（PQ-E）

> **本节只提建议，不做判定。**

| ID | 检查项 | 提示信号 | 默认档 |
|---|---|---|---|
| PQ-E1 | 实施主体 | 政府、平台公司、社会资本的角色与边界不清 | P1 |
| PQ-E2 | 土地取得方式 | 招拍挂、协议、作价出资等路径是否可行 | P1 |
| PQ-E3 | 收益封闭运行 | 是否具备片区封闭核算的政策条件 | P1 |
| PQ-E4 | 跨区域协调 | 涉及多个行政区／多个部门时，协调机制未提 | P2 |
| PQ-E5 | 政策依赖 | 结论高度依赖某一项尚未落地的政策（如区划调整、指标单列） | P0 |
