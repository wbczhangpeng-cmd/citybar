## A. 开工前

- [ ] 拿到**项目工作区**（`svg_output/` + `design_spec.md` + `spec_lock.md`），不只是 pptx
- [ ] 拿到落版的**偏差记录**，并已通读——尤其"结构级、用户已批"的那几条，不许当错误改回去
- [ ] 拿到**可编辑性基线**（落版验收表），否则复验时无法判断是谁改坏的

- [ ] 出了《精修范围确认单》：重点页建议 + 全篇拉齐项 + 预估工作量

- [ ] 用户给了清单的，已按其重排，且**优先级高于我的默认顺序**

## B. 段一（主体精修）

### 流程

- [ ] **先跑 `svg_quality_checker.py`**，过了才渲染（顺序反了是浪费时间）
- [ ] 用 playwright + chromium 渲染，**没用 cairosvg**（中文会变豆腐块）
- [ ] 检测顺序：渲染健全性 → H1/H2/H7 → H3/H6 → H4 → H8/H9 → 软规则
- [ ] 每页**首次编辑前已备份**到 `.review/backup/<page>.iter1.svg`
- [ ] 跑过 `check_deck_consistency.py`，跨页问题已进清单

### 判据

- [ ] 所有判据都来自 `visual-review.md` 的原文，**没有自己发明的替代判据**
- [ ] H4 涉品牌令牌的，**没有在页上修**，已升级并在报告里给了可执行建议
- [ ] 软规则遵守「拿不准就不动」，没有为了"更好"而去改
- [ ] 没有触碰 §3 禁改清单的任何一项

### 分级

- [ ] 每处改动都归了级（L1 / L2 / L3）
- [ ] L2 **全部出过前后并排图**，且每条都写了"代价"
- [ ] L3 的**一个都没动手**，已记录并说明退给谁
- [ ] `deck_wide` 类问题走的是**全篇统一方案**，没有逐页修补

## C. 段二（新增页接手）

- [ ] 已把四条**加页操作规范**交代给用户（只加页不改其他 / 不用一键美化 / 存 pptx / 优先 PowerPoint）
- [ ] **体检四项**全过：页数、已有页像素比对、字体表、配色令牌
- [ ] 体检不过时**停了**，没有在被改过的底稿上继续排版
- [ ] 每页判了形态（整页大图 / 主图+说明 / 多图拼版 / 图+数据），套的是现成槽位
- [ ] **没有为新增页新造页型**
- [ ] 每张图都挂了五级标签之一
- [ ] AI 生成图都标了「意向图」，**没有冒充实景或效果图**
- [ ] 缺图保留的是**显式占位**，没有拿网图顶
- [ ] 新页页码位置与全篇一致
- [ ] 已有页**一个字节没动**

---

## D. 可编辑性（放行条件）

- [ ] 跑了 `check_editability.py`，并与**落版基线逐页对比**
- [ ] 有"合格→不合格"的页，已**回滚该页修改**
- [ ] 全篇**零不合格页**
- [ ] 全篇**没有任何一页是整页截图**
- [ ] 文字没有转曲、图表还是原生对象、表格还是原生表格
- [ ] 没加动效；若加了，只有 fade，且加完复验过

---

## E. 一致性

- [ ] 字号：显式字号 ≤ 7 种，无"只在一页出现"的字号，无越阶梯
- [ ] 颜色：无令牌外颜色，无"只用一次"的临时取色
- [ ] 页码：无缺页，位置漂移 ≤ 2pt
- [ ] 标题顶端位置：主簇外的离群页已逐页确认（是刻意区分还是疏漏）
- [ ] 视觉密度：无连续 5 页以上雷同，无过载页

---

## F. 迭代纪律

- [ ] 单页最多 2 轮，第 2 轮是用户明确要求才开的
- [ ] 修完引入新硬伤的，已**回滚**并判 `needs_human`
- [ ] 没有为过检查而：删元素 / 降字号到阶梯以下 / 把内容并成图 / 换图表类型
- [ ] 修不动的已进《已知残留》，且写清**为什么修不动 + 建议找谁**
