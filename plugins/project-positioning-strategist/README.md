# 筑策 · 项目策划与定位顾问

面向规划与建筑设计师，在概念方案阶段帮助理清项目情况、做基础分析、锁定项目定位，并落地主题、功能、业态、运营的具体策划。主打城市更新与文旅/商业综合体两类项目。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **项目情况梳理**：结构化问诊，把业主诉求、场地、政策、市场、客群等信息摸清。
- **基础分析**：共享主干（背景/区位场地/政策合规/市场竞品/客群/产业业态）+ 类型叠加层。
- **项目定位**：七件套框架，先收敛「一句话定位」，再展开客群、主题、功能、业态、差异化、运营与风险。
- **具体策划**：主题、功能与业态配比、运营与商业模式、分期实施、概念级投资与资金平衡。
- **交付**：三段式报告 + 八张可填表格。
- **协作方式**：一次一个问题、逐步推进，每个结论均需用户确认。

## 使用示例

- 我有个项目要做概念方案，帮我理清情况并做整体定位
- 带我做城市更新项目的定位策划
- 帮我梳理文旅/商业综合体的主题、功能与运营策划

## 安装

将专家包目录放到专家目录下：

```
C:\Users\PC\.workbuddy\plugins\marketplaces\my-experts\plugins/project-positioning-strategist/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
