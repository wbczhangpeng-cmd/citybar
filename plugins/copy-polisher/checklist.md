# 交付前自检清单

每次交付润色稿、体检报告、对照表前逐条过。**任一红项未过，不得交付。**

---

## 一、三条红线（不可破）

- [ ] **数字与口径 0 改动**（逐条比对原稿）
- [ ] **结论与判断方向 0 改动**（只允许把已有的倾向说得更明确，不许加新论断）
- [ ] **章节结构 0 改动**（页序、章名、要点数量未变；合并拆分已在对照表说明）
- [ ] 如需整页重写，已事先提出并获用户点头
- [ ] 未新增任何事实、案例、数字、引用

## 二、AI味判定是否守规

- [ ] 没有"单点定罪"——每一处判定都说明了聚类依据（≥3 类 / 高频重复 / 同类≥3 处）
- [ ] 每处判定都给"命中项 + 位置 + 建议改法"，没有"这页很AI"式评语
- [ ] 没有用主观总分，只用了密度与分布
- [ ] 已区分「可改（表达）」「不可改（素材缺）」「不可动（红线）」

## 三、两遍是否都做了

- [ ] **第一遍删杂**：套话、排比、八股、判词腔、表态尾、空壳形容词
- [ ] **第二遍补实**：具体化（用已有信息）、加判断、调节奏
- [ ] 没有留下"干净但空"的无菌文（改后是否比改前**信息量更大**，而不是更少）
- [ ] 补实全部来自已有材料；素材不足的已标"需回上游补"，**没有自己编**

## 四、术语与专业性

- [ ] 已按项目类型启用对应语库
- [ ] 新增术语均标了来源；无来源的标了「待确认」且未流入正文
- [ ] 没有臆造标准条文、评分规则、政策条款
- [ ] 术语一致性核对完成，已出「术语统一表」
- [ ] 易错对已核（客流口径 / 出租率 / 坪效口径 / 回收期 / 投资额含不含地价）
- [ ] 单位统一（万/亿、元/万元、㎡/亩）

## 五、语体与风格

- [ ] 基调与皮肤符合《风格卡》，且用户已确认
- [ ] 版面文字与演讲备注分开，语体正确（一个给眼睛、一个给嘴）
- [ ] 版面文字超载处已提示并可移备注，没有静默压缩
- [ ] 标题已尽量改为结论式（不是名词式）
- [ ] 同一页没有两个同等权重的强调
- [ ] 全篇抽样朗读 5 页，听起来像同一个人讲的

## 六、禁用表述

- [ ] 无"国家级/世界级/唯一/首个/标杆/领先"等无依据表述
- [ ] 无"必将/一定/保证/确保成功"
- [ ] 无无出处的"数据显示/业内公认/专家普遍认为"
- [ ] 未把"规划中/意向/洽谈"写成既成事实
- [ ] 验筹《已被否定的假设黑名单》内容未出现（含换词变体）

## 七、交付完整性

- [ ] 润色稿字段与析纲脚本一一对应，可直接回填
- [ ] 修改对照表逐条齐全，含"为什么改 / 命中类型 / 是否动数字结论"
- [ ] 体检报告含改前/改后密度对比
- [ ] 视觉附注已给（主视觉大字 / 次要 / 建议删 / 文字量提示）
- [ ] 交接说明已附（本稿状态 / 待回上游 / 待裁定）

## 八、协作纪律

- [ ] 用户驳回的项已按意见重写，未辩解
- [ ] 术语有争议的已提示"需与验筹/筑策对齐"，未自行裁决
- [ ] 未越界做视觉（未指定字号、配色、版式）
