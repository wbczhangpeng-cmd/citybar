# 交付模板

五份模板：风格卡 → AI味体检报告 → 逐页润色稿 → 修改对照表 → 视觉附注。

---

## 模板 1 ·《风格卡》（第 2 步交付，须用户确认）

```markdown
- 补充类型特征：<若有跨界，说明主类型与附类型>
- 已启用语库：基础三层 + <新增语库名>

| 风格皮肤 | <商务精炼 / 专业严谨 / 文艺意象 / 国际化 / 口语直给> | <依据> |

## 三、术语表

|---|---|---|---|

### 3.2 本次新增（项目类型扩展）

## 四、禁用与慎用
```

## 模板 2 ·《AI味体检报告》（第 1 步交付，只诊断）

```markdown
# AI味体检报告

对象：<析纲脚本 / 某章>　字数：<n> 字　页数：<n> 页

## 一、总体判断
- 跨类聚集页：<n> 页（判 AI 味）
- 高频重复病灶：<病灶名>，出现在 <n> 页
- 最像 AI 的 5 页：P__、P__、P__、P__、P__

## 二、密度基线
| 类别 | 命中次数 | 每千字 | 说明 |
|---|---|---|---|
| 句式 | | | |
| 词汇 | | | |
| 逻辑修辞 | | | |
| 素材 | | | |
| 格式 | | | |
| **合计** | | | |

## 三、病灶明细（按页）
| 页码 | 命中项（编号） | 原文片段 | 建议改法 |
|---|---|---|---|
| P01 | B2、C2、E4（3 类） | "随着…从而…" | 删套话，落到具体动作 |

## 四、根因归类
- **可改（表达问题）**：<n> 处 —— 润色即可解决
```

## 模板 4 ·《修改对照表》（验收用）

| 页码 | 原文 | 改后 | 为什么改 | 命中类型 | 改动数字/结论 |
|---|---|---|---|---|---|
| P03 | 随着文旅融合战略的深入推进…… | 项目分三期…… | 删套话开场与表态尾 | B2 / C2 | 否 |

**结尾统计**
```
总修改 <n> 处；其中 删减 <n>、替换 <n>、重组 <n>
红线核验：数字 0 处改动、结论 0 处改动、结构 0 处改动
改前密度 <x>/千字 → 改后 <y>/千字（下降 <z>%）
```

**驳回回执格式**（用户可这样回）
```
P03 第二条不认可：原文"系统布局"是领导原话，保留。
P07 改后太口语，回到专业严谨。
其余通过。
```

## 模板 5 ·《给视觉专家的附注》

| 页码 | 主视觉大字（建议） | 次要信息 | 建议删 | 文字量提示 |
|---|---|---|---|---|
| P03 | 住宿是缺口，不是观光 | 过夜率 32% vs 同类 45%–60% | 第三、四行重复表述 | 版面上限已满，备注承接解释 |

**强调层级原则**
1. 一页只有**一句**做主视觉大字（通常是结论句）
2. 支撑数据做第二层（图表或数字块）
3. 解释性文字**全部下沉到备注**
4. 同一页不要出现两个同等权重的强调（加粗/变色/放大只保留一种手段）
