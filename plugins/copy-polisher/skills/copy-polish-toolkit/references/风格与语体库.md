# 风格与语体库

两层制：**基调（谁在看，管得体）× 皮肤（什么味道，管多样）**。基调错了会不得体，皮肤单一会整篇一个味。

---

## 一、语体基调（5 档）

### 1. 政府汇报
- **气质**：稳、规范、有站位，落到"能落地、谁受益"
- **写法要领**：先讲依据（政策/规划/上位文件），再讲举措，最后讲成效与保障；多用短句 + 事实，少用品牌化口号
- **特征用词**：与上位规划衔接、因地制宜、统筹、试点、示范、配套完善、民生改善、可持续
- **避免**：过度商业口吻（"现金流模型""爆款"）、第一人称"我们认为"（改"本项目"）、夸张承诺（"必将"）
- **数据呈现**：给口径与来源，宁可粗到"约""以上"，也不要无出处的精确

### 2. 投资路演
- **气质**：直接，讲钱、讲风险、讲退出
- **写法要领**：结论前置（回报、回收期、关键假设），一页一个"投资人关心的问题"；主动披露风险比被问出来更可信
- **特征用词**：投资强度、EBITDA、静态/动态回收期、敏感性、爬坡期、退出路径
- **避免**：宏大叙事、文化情怀、"打造标杆"；避免把风险藏在附录
- **数据呈现**：口径必须写清（含不含地价、含不含财务费用）；给区间不给单点

### 3. 内部决策
- **气质**：短、狠，只讲决策点
- **写法要领**：每页一句话说清"要定什么、选项是什么、建议哪个、代价是什么"
- **特征用词**：需决策、方案A/B、影响、前置条件、待定项
- **避免**：铺垫、背景复述、给领导补课
- **数据呈现**：能一页一表就不写两页；关键数字加粗不超过 3 处

### 4. 专业评审
- **气质**：克制、可核查，不与评审专家抢话
- **写法要领**：假设写在明面上，方法与口径可复核，主动标注不确定项
- **特征用词**：依据、口径、假设、测算、限定条件、待补充
- **避免**：绝对化结论、情绪化表达、把推断写成实证
- **数据呈现**：每个数字带来源；不能给的写"待补"

### 5. 品牌传播
- **气质**：有情绪、有记忆点，可传播
- **写法要领**：一个核心意象撑一页，短句为主，可与受众对话（"你可以…"）
- **特征用词**：画面感动词、具体场景、人的动作
- **避免**：空洞形容词堆叠（这恰好是 AI 味的重灾区——用场景替代形容词）
- **数据呈现**：少用表格，用一个数字打点即可

## 二、风格皮肤（5 档）

| 皮肤 | 句长 | 句法 | 典型手法 | 适合页型 |
|---|---|---|---|---|
| **商务精炼** | 短（12–20 字） | 动宾结构，主语常省略 | 结论前置、名词短句、数字打头 | 摘要、策略、投资 |
| **专业严谨** | 中长（20–40 字） | 主谓完整，限定成分齐全 | 假设前置、口径标注、条件句 | 分析、测算、合规 |
| **文艺意象** | 长短交错 | 允许倒装与省略 | 一个意象 + 一个事实、少用抽象名词 | 定位、愿景、文化章节 |
| **国际化** | 短中 | 主动语态、少用四字堆叠 | 中英术语对齐、单句单义 | 对外招商、国际对标 |
| **口语直给** | 短 | 有主语，可带语气 | 直接说判断、可自问自答（仅一页一次） | 内部决策、路演开场 |

**皮肤可以逐章切换**，例：`第一章 分析（专业严谨）→ 第二章 定位（文艺意象）→ 第三章 策略（商务精炼）→ 第四章 投资（商务精炼 + 数字打头）`

## 三、页面类型语体（按页定型）

| 页型 | 版面文字要求 | 备注要求 |
|---|---|---|
| **封面** | 主标题 ≤ 一行（结论式或意象式）；副标题给范围/时间/主体；不写三个以上信息 | 一句话交代"今天讲什么、讲给谁听、要什么结果" |
| **目录** | 只列章名，不加描述句 | 讲清逻辑关系（为什么是这个顺序），不是念目录 |
| **摘要/结论** | 一页纸结论：1 个总判断 + 3 条支撑（可 2 或 4 条，别凑三） | 说清"这页最重要的一句话是什么" |
| **分析页** | 图表为主，文字只写"读图结论"，不重复图上数字 | 讲怎么读图、哪里是异常、所以说明什么 |
| **策略/策划页** | 动作开头（做什么），不是名词开头（什么体系） | 讲清"为什么这么做"和"不这么做会怎样" |
| **投资/测算页** | 一表 + 三条结论；口径用小字注 | 讲假设与风险，先讲最脆的一环 |
| **结论/下一步** | 三件以内的具体动作 + 时间 + 责任方 | 收在动作上，不升华 |

## 四、版面文字 vs 演讲备注（对照示例）

**版面（给眼睛看）**
```
住宿是缺口，不是观光
· 过夜率 32%，低于同类项目 45%–60%
· 现有床位 780 张，旺季缺口约 400 张
· 建议二期补 300 间客房
```

**备注（给嘴说）**
```
这页想说的是：我们缺的不是游客，是让游客留下来的条件。
过夜率 32%，同类项目一般能到 45% 到 60%，这个差距就是我们能拿的空间。
床位这块要注意，780 张是现有口径，包含了周边民宿，被问到的话要能说清统计范围。
如果领导问为什么不先做门票经济，这里可以先垫一句：门票收入天花板已经很清楚，二消才是增量。
```

**要点**：版面写"结论 + 依据"，备注写"怎么讲 + 会被问什么 + 怎么答"。

## 五、基线与皮肤的冲突处理

- **基调管红线**：政府汇报下，皮肤再"文艺"，也不许出现夸张承诺与无据排他表述
- **皮肤管密度**：皮肤决定句子长短与修辞强度，不改变事实与结论
- **冲突时**：先满足基调的得体性，再在得体范围内做皮肤

## 六、多章混用时的统一性检查

- 同一层级（同级章节）的皮肤应一致；跨级可不同
- 一章之内不要混 3 种以上皮肤
- 术语、称呼、数据口径全篇统一（见 `专业词库.md`）
- 全篇抽样 5 页朗读：听起来是否像同一个人讲的
