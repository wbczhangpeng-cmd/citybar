# 专业词库（三层 + 项目类型扩展）

**术语用错比句子像 AI 更致命**——外行看不出句式问题，但一眼能看出术语不专业。本库分基础三层，再按项目类型扩展。

---

## 一、第一层：行业术语与易错对

### 1.1 文旅

| 正确用词 | 常见错用 | 口径提醒 |
|---|---|---|
| 接待游客量（全域） | 与"购票人次"混用 | 全域口径含免费开放、过境；做收入测算必须用购票口径 |
| 购票人次 | 写成"游客人数" | 与全域口径差 2–5 倍，不可混算 |
| 人均消费 | 客单价 | 人均消费分母是同口径客流；客单价多用于零售/餐饮单笔 |
| 二消（二次消费） | 非票收入 | 二消指园内餐饮零售体验；非票收入还可能含租金、分成、补贴 |
| 过夜率 | 留宿率、住宿率 | 过夜游客 ÷ 接待游客 |
| 承载量（日/瞬时） | 只写"承载量" | 必须标日承载还是瞬时承载 |
| 游线 | 动线 | 景区用"游线"，商业用"动线"，混用不专业 |
| A 级景区 | — | 评定依据《旅游景区质量等级的划分与评定》，**具体条款须查原文，不凭记忆引用** |
| 淡旺季 | 只说"季节性" | 需给月份分布，否则测算无法验证 |

### 1.2 商业

| 正确用词 | 常见错用 | 口径提醒 |
|---|---|---|
| 出租率 | 招商率、开业率 | 出租率=已签约面积/可租面积；开业率=已开业面积；三者不可互换 |
| 坪效 | 租金坪效 | 坪效=营业额/可租面积；租金坪效=租金/可租面积；用建筑面积算会虚高 |
| 可租面积 | 建筑面积、计容面积 | 商业测算一律用可租面积 |
| 主力店 / 次主力店 | 统称"大店" | 主力店通常指面积与引流贡献双高的锚店 |
| 抽成租金 | 提成租金 | 与固定租金取高或取低须写明 |
| 免租期 / 装补 | — | 招商成本必项，不进测算等于漏成本 |
| 客流（进店） | 与商圈客流混用 | 进店客流 ≠ 商圈客流，转化率分母须界定 |

### 1.3 城市更新

| 正确用词 | 常见错用 | 口径提醒 |
|---|---|---|
| 容积率 | 建筑密度、开发强度 | 三者不同，不可并用为一个概念 |
| 计容建筑面积 | 建筑面积 | 计容不含地下、架空等，直接影响可售比 |
| 拆迁/征收成本 | 统称"土地成本" | 含补偿、过渡安置、时间成本 |
| 可售比 | 销售比例 | 需规划依据，不能凭意愿设定 |
| 资金平衡 | 财务平衡、现金流平衡 | 更新项目惯用"资金平衡"，指全周期收支相抵 |
| 更新单元 | 项目地块 | 政策术语，涉及政策适用与审批路径 |

### 1.4 住宅

| 正确用词 | 常见错用 | 口径提醒 |
|---|---|---|
| 去化率 | 去化周期 | 去化率＝当期售出/当期推出；去化周期＝存量卖完所需月数，两者不可互换 |
| 得房率 | 使用率 | 得房率＝套内/建筑面积；使用率口径另有定义，不可混用 |
| 楼面价 | 地价、地价单价 | 楼面价＝地价/计容建面，与亩单价不是一回事 |
| 计容建筑面积 | 建筑面积、总建面 | 计容不含地下与架空，直接影响可售比与楼面价 |
| 可售面积 | 总建筑面积 | 住宅测算一律用可售面积 |
| 精装标准（元/㎡） | 装修档次（模糊） | 必须给单价，否则成本与溢价都无法校验 |
| 车位配比 | 车位数 | 配比＝车位/户（或/百㎡），车位数单独看无意义 |
| 首开去化率 | 开盘售罄（话术） | 首开去化率必标推盘量与认购口径 |

### 1.5 产业园区

| 正确用词 | 常见错用 | 口径提醒 |
|---|---|---|
| 入驻率 | 出租率 | 入驻率按企业数或面积算，须标口径；与出租率不同 |
| 亩均产值 / 亩均税收 | 单位面积产值（模糊） | 分母是用地面积还是建筑面积须写明，报政府多用亩均 |
| 标准厂房 | 厂房（泛称） | 标准厂房指通用化设计、可分可合的载体产品 |
| 研发办公比 | 办公占比 | 指研发载体与办公载体的面积比，与配套比不同 |
| 载体 | 物业、房子 | 产业地产惯用"载体"，含厂房/研发/中试/仓储 |
| 产业链环节 | 产业（泛称） | 必须落到环节（研发/中试/制造/总部），否则招商无靶 |
| 准入退出机制 | 招商政策（模糊） | 指亩均指标、达产要求、低效腾退的制度安排 |

### 1.6 通用财务

| 正确用词 | 常见错用 | 口径提醒 |
|---|---|---|
| 投资总额（含/不含土地） | 只写"总投资" | 必须标含不含土地、含不含建设期利息 |
| 静态回收期 / 动态回收期 | 只写"回收期" | 两者差 1–3 年，必须标 |
| 营业收入 / 经营收入 | 营收（模糊） | 与"营业外收入""补贴收入"分开 |
| 运营成本率 | 成本率 | 是否含折旧与财务费用必须写明 |
| EBITDA | 毛利 | 非同一概念，不可替代 |
| 敏感性分析 | 风险分析（泛称） | 应指明变量（客流/单价/租金/成本） |

## 二、第二层：群体专用语

| 群体 | 惯用表达 | 慎用/忌用 |
|---|---|---|
| **政府口径** | 与上位规划衔接、因地制宜、统筹推进、试点示范、配套完善、民生改善、存量盘活、片区统筹 | 现金流模型、爆款、ROI、私域流量 |
| **投资方口径** | 投资强度、EBITDA、回收期、敏感性、爬坡期、退出路径、资金平衡 | 文化情怀式论述、无口径的"预计收益" |
| **设计/工程口径** | 动线、业态落位、荷载、机电容量、层高净高、柱网、消防分区、无障碍 | 把"业态"说成"商业种类"；把"落位"说成"摆放" |
| **运营口径** | 坪效、人效、开业率、复购率、客诉率、活动转化 | — |

## 三、第三层：慎用与禁用词

**慎用（需有依据才可用）**：标杆、领先、首创、示范、唯一、区域首个、国家级、世界级
**禁用（任何情况不写）**：必将、一定、保证、确保成功、彻底解决、行业第一（无第三方认定）

## 四、项目类型语库扩展机制

### 4.1 四步建库

```
① 定义项目类型 → ② 列该类型核心术语 → ③ 标注来源 → ④ 出易错对与口径提醒
```

### 4.2 已备语库（示例，按需扩充）

**住宅**
得房率（套内/建筑面积）、容积率、梯户比、层高、开间进深、去化率、去化周期、开盘去化率、认筹比、车位配比、精装标准、物业费
*易错*：得房率 ≠ 使用率；去化率（当期售出比例）≠ 去化周期（卖完所需月数）

**城市片区规划**
用地结构、开发强度、公共服务配套、职住平衡、15 分钟生活圈、TOD、道路网密度、绿地率、城市设计导则
*易错*：容积率与开发强度不可互替；绿地率 ≠ 绿化覆盖率

**景区规划**
游线组织、日/瞬时承载量、集散中心、A 级景区标准、游览服务设施、智慧景区、门票与联票政策
*易错*：承载量不标日/瞬时；A 级标准条款须查原文

**二次元主题**
IP 授权、角色场景还原、圈层用语、同人生态、谷子店（周边零售）、主场馆与次元街区、cos 与摄影区、声优/画师活动
*易错*："二次元"是圈层文化而非业态名，避免写成"二次元业态"笼统打包；IP 授权有期限与地域范围，须标

**康养**
客群年龄分层、自理/介助/介护、医养结合、护理比、康复配套、候鸟式/长住式
*易错*：护理比（护理员/床位）口径须标；"医养结合"涉及资质，不可泛用

**产业园区**
主导产业、产业链环节、亩均产值、亩均税收、标准厂房、研发办公比、入驻率、企业培育
*易错*：入驻率 ≠ 出租率；亩均指标须标统计口径

### 4.3 防幻觉约束（强制）

- 新增术语**必须标来源**：`行业规范 / 国家标准 / 政策文件 / 甲方口径 / 验筹事实包`
- **无来源的标「待确认」**，不得流入正文
- **不得自造定义、不得臆造标准条文与评分规则**（如"A 级景区要求 XX 项"这类必须查原文）
- 新增语库须在《风格卡》中单列，供用户核

## 五、术语一致性核对（每篇必做）

### 5.1 检查项

1. 同一概念是否用了多个词（客流/人流/客流量/游客量）
2. 同一指标是否混了口径（全域人次 vs 购票人次）
3. 同一主体称谓是否统一（本项目 / 该项目 / 项目 / 园区）
4. 数字单位是否统一（万/亿、元/万元、㎡/亩）
5. 时间表述是否统一（2024 年 / 去年 / 上年）

### 5.2 输出「术语统一表」

| 原用词（各处不同写法） | 统一为 | 出现页 | 依据 |
|---|---|---|---|
| 客流量 / 人流 / 游客量 | 接待游客量（全域） | P05、P12、P18 | 事实包口径 |
| 出租率 / 招商率 | 出租率 | P24、P27 | 按已签约面积口径 |

### 5.3 争议处理

术语有分歧时：给出两种用法 + 各自依据 → 提示"需与验筹/筑策口径对齐" → **不自行裁决**。
