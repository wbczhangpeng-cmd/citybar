# 文案润色工具箱

本工具箱是「淬言」的作业手册。核心原则：**聚类才判、两遍才改、红线不碰。**

## 作业铁律

1. **三条红线**：不改数字与口径、不改结论与判断、不改章节结构。整页重写须用户点头。
2. **单点不判**：命中一个词不是问题，≥3 类聚集或高频重复才判。
3. **两遍走完**：删杂之后必须补实（具体化 / 加判断 / 调节奏），否则只是"无菌文"。
4. **补实不许造**：具体化只能用已有信息；素材不足就回退上游，不编细节。
5. **先试 3 页**：不先对齐调性就全量写，等于整篇返工。
6. **术语只用一个词**：同概念同词、同指标同口径，出统一表。
7. **不做视觉**：只给强调层级与文字量建议，不指定字号版式。

## 冲突裁决顺序

`用户明确指示 > 验筹事实包（含黑名单） > 本工具箱 > 外部技能（humanizer 等）`

外部技能用于补扫描能力，但其"加第一人称 / 加幽默 / 允许杂乱"等建议，在正式汇报语境下一律不采用。
