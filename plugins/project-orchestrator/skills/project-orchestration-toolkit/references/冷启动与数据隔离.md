# 冷启动与数据隔离

> **这一份管的是"哪些东西不许进本项目"，比任何方法手册都优先。**
> 方法错了可以改，数据串了整份方案都是假的——而且看不出来。

---

## 一句话

**每次新任务 = 一个全新项目。** 除了主人**在本次对话里亲自给出**的资料，
任何历史项目的结论、数字、案例、文件路径、话术偏好，一律不得进入本项目。

---

## 四条硬规则

### 1. 一项目一空间

开工第一步定目录：`<项目名>-<YYYYMMDD>/`，`--root` **只许指它**。

**禁止**把下面这些当 root：

| 不行 | 为什么 |
|---|---|
| 桌面、下载、文档根目录 | 里面的东西跟你这个项目没关系 |
| 上一个项目的目录 | 素材、台账、交付物全在里面，一读就串 |
| 装着多个项目的父目录 | 你会顺手 ls 到隔壁项目 |
| 本次没提过的任何盘符路径 | 不是给你的，就不要看 |

### 2. 不主动找料

不许到项目空间之外去"参考一下上次那个"。
**没给你，就是没有。** 缺料就写 `{待补}` 并说明缺什么，等主人给。

这条最容易被自己说服：*"我记得上个项目有一份类似的竞品表，拿来改改就行"* ——
**不行。** 那是以别人的项目事实冒充本项目事实。

### 3. 不承接结论

上个项目的定位、主题、功能配比、话术、案例库、数字，
即使你还记得，也**不许用、不许提、不许"顺手沿用"**。

判断标准很简单：**这一条如果换成另一个客户还成立吗？**
如果它只在某个具体项目里成立，那它就是历史数据，不是工作方法。

### 4. 给的才算数

- 主人**贴进对话的文字** → 算本项目输入
- 主人**点名的文件／路径** → 算本项目输入，且只读那些
- 主人**上传的附件** → 算
- 其余一切 → 不算

## 开工三问（缺一不许开工）

| # | 问什么 | 用来干什么 |
|---|---|---|
| 1 | **本项目叫什么** | 建空间名、写项目标识、防止和旧项目混 |
| 2 | **资料在哪个路径** | 定 `--root` 和可读范围，范围外一律不读 |
| 3 | **新做还是续做** | 新做＝空空间；续做＝必须指名上次那个空间路径 |

> 第 3 问答"续做"时，仍然要过隔离闸：只有空间里的**项目标识**和本次项目名一致，才算续做。

---

## 机器闸：`check_project_isolation.py`

```bash
python toolbox/check_project_isolation.py --root <项目空间> --project-name <本项目名>
python toolbox/check_project_isolation.py --root <项目空间> --project-name <本项目名> --init
```

| 脚本回报 | 含义 | 怎么办 |
|---|---|---|
| `NEW` | 目录不存在或为空 | 全新项目，加 `--init` 建空间，可以开工 |
| `SAME` | 标识里的项目名和本次一致 | 同一项目续做，放行 |
| `SUSPECT` | 目录有内容但没有项目标识 | **停。** 可能是上个项目的空间，回问主人 |
| `PARENT` | 你指到了装着多个项目的父目录 | **停。** 指到具体项目那一层 |
| `WRONG` | 标识里的项目名和本次不一致 | **停。** 拿错目录了 |

退出码：`0` 放行／`1` 停／`2` 用法错误。

**判不准一律停。** 误停只是多问一句话；误放会把上个项目的数据带进新项目，
而且要到很后面才发现，前面全是白做。

## 项目标识长什么样

`<项目空间>/00-项目标识.json`，由 `--init` 写入，之后不用手改：

```json
{
  "project": "本项目名称",
  "created": "2026-10-29 21:50",
  "root": "……绝对路径……",
  "note": "本文件标记该目录属于哪个项目。写了它，别的项目就不会误用这个空间。"
}
```

**它不依赖目录名**——目录可以改名，标识跟着文件走。

---

## 发现自己已经串了怎么办

1. **立刻停手**，不要把错的那句"顺手改掉"继续往下写
2. 明确说一句：**"这条来自历史项目，不属于本项目"**，并指出是哪一处
3. 那一段**作废重做**，不要修补
4. 如果是主人自己给的资料里带的旧项目信息（比如他贴了一份老报告）→ 问清楚：
   "这份里带的是另一个项目的内容，要当参考还是当本项目资料？"

## 段末验收多一条（秉钧专用）

验收单里加一行，和"有没有缺项"并列：

| 检查 | 怎么核 |
|---|---|
| **有没有引入非本项目材料** | 抽查 3 个关键结论／数字／案例，问一句"这个出自本项目哪份资料"；答不上来就是串了 |

**这一条不过，别的问题都不用看了**——数据串了，后面判得再准也是给别人判的。

## 一句话记法

> **方法可以带着走，数据一律留下。**
