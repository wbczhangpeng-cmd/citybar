# 图片落地规范

立象出的是《逐页图位分配表》，你负责把它变成真实文件。**这张表最容易出错的地方不是拍得难看，是拍错了性质——或者干脆一张都没落地。**

## 零、先分清两类，分错了就 0 图

| 类别 | 含哪些 | 谁来弄 | 缺了算谁的 |
|---|---|---|---|
| **可自行产出** | 分析图（自绘）、意向图（AI 生成）、生成装饰图 | **你，本轮内完成** | **我们的活。缺了就是没干** |
| **必须外部提供** | 实景照片、效果图 | 甲方 / 设计单位 | 甲方那边。占位 + 进缺口清单 |

> **真实事故**：一份 58 页文旅汇报交出来 **0 张图片**。图位表有 17 项，
> 几乎全标"待甲方提供"，而其中**动线图、矩阵图、面积分析图本来都是能自己画的**。
> 一句话总结：**"等甲方"当挡箭牌，挡住了自己的活。**

### 必要性三档（来自立象/析纲，你要照它执行）

| 档 | 你该做的 |
|---|---|
| **P · 必须有** | 拿不到就**不许交付这一页**。可自绘/AI 的当场做出来；外部提供的报"本页缺 P 档图，不许定稿" |
| **S · 应该有** | 占位 + 进缺口清单，可以带病前进 |
| **O · 可选** | 版面自行处理，不做也行 |

## 一、五级标签（标签错了比图丑严重得多）

| 标签 | 谁提供 | 你的动作 | 缺了怎么办 |
|---|---|---|---|
| **实景照片** | 甲方或已获授权 | 落地、按图位表比例裁切、标注出处 | 占位 + 进缺口 +（P 档）**报不许交付**。绝不用网图、绝不用 AI 图冒充 |
| **效果图** | 设计单位 | 落地、不裁切、标注设计单位 | 占位 + 进缺口 +（P 档）**报不许交付**。AI 不得代出 |
| **分析图** | **你基于已核验数据自绘** | 原生形状绘制（不许整张截图贴入）；数据齐才画 | **数据不齐才可不画**，且必须报具体缺哪个数 |
| **意向图** | **你生成** | AI 生成，图上标"意向图" | **不许留白**。生不出来就换构图重试，最多 3 次，仍失败报技术障碍 |
| **生成装饰图** | 你生成 | 仅限无信息量的氛围/肌理/背景 | 可省。不得承载数据或空间主张 |

## 二、三条红线

1. **AI 生成的图不得承载数据**（不能画个饼图当配图、不能在图上写"客流 120 万"）
2. **AI 图不得冒充实景**（一张"看起来像某市的照片"拿去汇报，等于伪造调研）
3. **AI 图不得冒充本项目效果图**（这是最严重的一种，性质上属于伪造设计方案）

## 三、生成意向图的具体做法

**目标**：同一页里的图不能三种味道；同一份稿里的图不能四种风格。

1. **建立风格词底稿**（全篇一份，不要每图现编）：
   ```
   [媒介]摄影质感 / 手绘插画 / 水彩 / 拼贴
   [光线]晨昏低角度 / 阴天柔光 / 夜景灯光
   [色调]对应 design_spec 的色板，写具体色相倾向
   [构图]横幅远景 / 中景人物 / 俯拍 / 平视
   [氛围]克制 / 热闹 / 苍凉 / 温暖
   [排除]不要文字、不要水印、不要明显人脸、不要 logo
   ```
2. **每张图只改主体描述，风格词原样复用**
3. **出图后先看一致性**：把同组图并排看一遍，色调和光线不齐就重出那一张，不要凑合
4. **落位时看裁切**：宽幅图放竖版位会砍掉主体；先按槽位比例生成或裁切

**生成前先问一句**：这张图是「意向图」还是「效果图」？
- 意向图 = 表达氛围与可能性，AI 可以出，但必须标"意向图"
- 效果图 = 表达方案确定性，**只能设计单位出**。你不会知道甲方最终建成什么样

## 四、占位怎么留（**P 档不许只占位**）

用统一样式的原生矩形 + 一行说明文字，**不要用虚线框就直接导出**：

```
[ 实景照片占位 · 滨河生态园主入口 · 需甲方提供 · P 档 ]
```

要求：
- 明确写**要什么图**、**要谁给**、**P 还是 S**
- 占位框在本批次交付时**必须点名**，让用户知道这里还缺东西
- **P 档的占位框 = 未完成，不是交付状态。** 交付前必须让用户知道这几页还不能用
- S 档占位可以带病交付，但要在报告里写明

## 五、检索来的图（能用但有限制）

- 只用于**氛围参考**，标签一律"意向图"
- 必须核对**授权**（可商用、无署名限制或有署名方式）
- 不得用于实景、不得用于本项目效果、不得用于证明任何事实
- 图上带水印、带明显品牌标识的，一律不用

## 六、出处与合规

- 实景与图纸：记录**提供方 + 日期**，需要时在页脚署名
- 检索图：记录**来源链接 + 授权类型**
- 地图：**必须合规来源**（有审图号或使用合规底图服务），不得用 AI 生成地图当区位图
- 生成图：记录 **prompt + 模型 + 日期**，万一被问"这图哪来的"能答上来

## 七、交付时怎么报：图文到位率报告

**别写"图片已处理完毕"。** 报这七个数：

| 指标 | 数 | 判据 |
|---|---|---|
| P 档页数 | __ | 应 ≥ 总页数 35% |
| P 档已到位 | __ / __ | **100%（可自行产出部分）** |
| S 档已到位 | __ / __ | ≥ 80% |
| 可自行产出总数 | __ 张 | 分析图 __ ｜ 意向图 __ ｜ 装饰图 __ |
| **可自行产出完成率** | __% | **必须 100%**。不到就是没干完 |
| 外部提供缺口 | __ 张 | 单列成「交付前置条件」，含索取对象与时点 |
| 全篇图片覆盖页占比 | __% | 零图页逐页说明理由 |

**跑脚本核，不要凭记忆填**：

```bash
python scripts/check_image_coverage.py 交付物/deck.pptx --plan 图位分配表.md --json vis.json
```

退出码 `0` 达标 / `1` 覆盖不足 / `2` **P 档缺图（最严重）**。

> **这份报告不通过 = 不许交付。** 尤其「可自行产出完成率」——
> 它衡量的是**我们有没有把自己的活干完**，跟甲方给不给材料无关。
