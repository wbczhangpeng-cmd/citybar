## 二、依赖清单

| 包 | 用途 | 缺了会怎样 |
|---|---|---|
| `python-pptx` ≥0.6.21 | SVG → 原生 pptx | 根本无法导出 |
| `XlsxWriter` ≥3.0 | 图表导出 | 图表页失败 |
| `skia-pathops` ≥0.9.2 | 合并形状物化 | 复杂形状退化 |
| `uharfbuzz` ≥0.50 | 文字整形与轮廓 | 文字排版错位 |
| `Pillow` ≥9.0 | 图片处理与切分 | 图片处理失败 |
| `numpy` ≥1.20 | 图片分析 | 分析图失效 |
| `PyYAML` ≥6.0 | 模板注册 | 模板装不上 |
| `flask` ≥3.0 | 实时预览服务 | 预览起不来（不阻塞生成） |

一键补齐（pypi 直连可用；若代理开着可加 `--proxy=http://127.0.0.1:7897`）：

```bash
python -m pip install python-pptx XlsxWriter skia-pathops uharfbuzz Pillow numpy PyYAML flask
```

## 三、字体（已确认可用）

| 类型 | 可用字体 |
|---|---|
| 无衬线中文 | 微软雅黑（msyh / msyhbd / msyhl）、黑体（simhei）、思源黑体（SourceHanSansCN Regular/Medium/Bold）、阿里巴巴普惠体（Regular/Medium）、Noto Sans SC |
| 衬线中文 | 宋体（simsun / simsunb）、Noto Serif SC |
| 西文 | Noto Sans / Noto Serif 全字重、Cambria |

**规矩**：
- 只用上表内的字体。`design_spec` 里点了没有的字体 → **报告并提议替代**，不要静默换成默认字体（换了字宽，整页排版全变）
- 字体名写**中文全名或系统名**，别写 "Source Han Sans" 又指望它命中 `SourceHanSansCN`——先 `ls /c/Windows/Fonts` 确认
- 缺字重时**宁可换字体，不要伪粗**（伪粗在 PPT 里会掉字重）

## 五、运行时注意

- Windows 上 `python3` 可能是 WindowsApps 存根（退出码 9009、无输出）→ **改用 `python`**，别误判成校验失败
- 实时预览默认从 6060 找空端口；`--port N` 是严格绑定，占用了就报错而不是换端口
- 端口冲突、预览起不来 → **明说，然后继续生成**，预览不是生成的前置条件
- 生成期间**保持预览服务运行**，直到用户点"退出预览"或明确要求关闭
