# 落版 · 自检清单

交付前逐条过。**任何一条不过，就不算完成。**

## 一、三条锁（最容易被违反的）

- [ ] 页序、页数、页标题与析纲/立象 §IX **逐条一致**，没增没删没重排
- [ ] 所有数字与口径来自验筹事实包，**没有一个是自己估的、"约"出来的**
- [ ] 验筹黑名单里的假设**一个字都没出现**（含图表标题、图注、备注）
- [ ] 配色、字号、页型定义**一处未改**；改了的话已退回立象而不是自己动手

## 二、事实纪律

- [ ] 每个 `{待补}` 都进了缺口清单，写清"缺什么、谁给、影响什么"
- [ ] 缺整页内容的页排成了空版，**没有删页**
- [ ] 文案与页型不合的处理都在偏差记录里，成因写得具体
- [ ] 没有任何"约""左右""预计"在替代一个本该有的确切数字

## 三、可编辑性

- [ ] 跑了 `check_editability.py`，**0 页不合格**
- [ ] 文字全部原生文本框，无转曲
- [ ] 图表全部原生对象（可改数据），无图表截图
- [ ] 表格全部原生表格，无表格图片
- [ ] 关系图/矩阵图用原生形状拼，**无整页截图**
- [ ] 图片只用于照片/意向图/图纸，**没有一张图承载文字信息**
- [ ] 组合层级克制，没有为好看而过度嵌套

## 四、图片

- [ ] 每张图都有标签（实景 / 效果图 / 分析图 / 意向图 / 生成装饰图）
- [ ] AI 生成图**没有**承载数据、**没有**冒充实景或效果图
- [ ] 该由甲方/设计单位提供的，缺了就占位 + 列清单，**没用网图顶替**
- [ ] 地图是合规来源，非 AI 生成
- [ ] 交付文件里**没有残留虚线占位框**

## 五、流程门位

- [ ] `attribution_guard.py` 通过，没绕过
- [ ] 走的是 Default 路线，没为了快切 Quick
- [ ] 合并确认单**由用户签的**，不是我代签的
- [ ] 首 5 页经过用户确认才继续
- [ ] 早期门（P05 后）与最终门都跑了，且最终门 0 errors
- [ ] 每批交付时问了"继续还是改"，没有闷头刷完

## 六、失败处理

- [ ] 同一问题没有超过 3 轮还在硬试
- [ ] **没有**为过检查删页、并页、抽图表
- [ ] **没有**自行降级（图表贴图、文字转曲）
- [ ] 环境问题（缺依赖/字体/图）是停下报的，不是静默换方案
