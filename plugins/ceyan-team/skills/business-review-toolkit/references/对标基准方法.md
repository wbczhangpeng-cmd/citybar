# 对标基准方法

对标的目的不是"找几个好看的项目撑场面"，而是**给方案的每个关键假设找一个来自现实的合理区间，然后量出它偏离了多少。**

---

## 一、选样规则

### 1.1 优先级（严格按序）

| 序 | 维度 | 说明 |
|---|---|---|
| 1 | **同类型** | 观光景区 / 度假区 / 文旅小镇 / 城市文旅综合体 / 商业综合体 / 更新改造型街区——类型不同，逻辑不通 |
| 2 | **同规模** | 建筑面积、投资额、年客流在同一量级（±1 个量级内） |
| 3 | **同客群结构** | 本地复购型 / 区域引流型 / 全国目的地型；团散比、过夜率相近 |
| 4 | **同区域（加分项，非硬条件）** | 同城或同省优先（消费能力、客源半径更接近），但不是门槛 |

> **区域后置的原因**：很多城市找不到 3 个同类型同规模的本地样本；硬要凑区域，就会拿不 comparable 的项目硬比。全国性样本池 + 明确的差异校准，比"就近凑数"可靠。

### 1.2 数量与构成

- **3–5 个**。少于 3 个不足以成"区间"，多于 5 个则每个都研究不深
- 建议构成：**2–3 个"最可比"主样本 + 1–2 个"边界参照"**（一个做得特别好的作上限、一个失败的作下限）
- **必须至少包含 1 个反向样本**（经营不佳、客流远低于宣传、流拍或退出的项目），否则基准会系统性偏乐观

### 1.3 禁止

- 拿全国知名标杆（阿那亚、袁家村、大唐不夜城一类）当**基准**——它们只作**上限参照**
- 拿不同量级项目直接类比（3 万㎡ 对 60 万㎡）
- 拿"规划中/在建项目"的**预期**数据当已实现数据
- 拿开业首年爆发期数据当稳态数据（**必须标注运营年限**）

## 二、可比性矩阵（每个样本必填）

| 字段 | 说明 |
|---|---|
| 项目名称 / 所在地 | 城市能级（一线/新一线/地级市/县域） |
| 类型 | 观光 / 度假 / 小镇 / 城市综合体 / 街区更新 |
| 体量 | 建筑面积、占地、投资额 |
| 开业时间 / 运营年限 | 判断是否处于爬坡期、成熟期、衰退期 |
| 客源结构 | 本地占比、省外占比、团散比、过夜率 |
| 票价结构 | 大门票 / 免费 / 联票 / 二消主导 |
| 年客流 | 数值 + 口径（购票人次 / 全域人次） |
| 人均消费 | 门票 + 二消拆分 |
| 经营指标 | 坪效、出租率、租金水平、成本率（可得则填） |
| 数据来源与分级 | A/B/C + 获取时间 |
| **可比性判断** | ★高度可比 / ○参考 / △仅作上限下限 + **一句差异说明** |

**降权规则**：差异跨城市能级、跨客源结构（如全国目的地 vs 本地社区型）、跨票价模式（免费街区 vs 收费景区）的，只能作○或△，不得进入基准区间计算。

---

## 三、指标口径定义（同名不同义是本环节最大的坑）

| 指标 | 口径必须写清 | 常见混淆 |
|---|---|---|
| 年客流 | 购票入园人次 / 全域接待人次 / 含免费开放人次 | 用全域人次算需要买票的收入 |
| 人均消费 | 分母是同口径客流；是否含住宿、是否含门票 | 把团客结算价当散客票价 |
| 二消占比 | 二消收入 ÷ 总收入；二消含哪些品类 | 把租金算成二消 |
| 坪效 | 年营业额 ÷ 可租/可营面积（不是总建筑面积） | 用建筑面积算坪效，虚高 30%+ |
| 出租率 | 已签约面积 ÷ 可租面积；是否含短租与临时摊位 | 用"招商率"替代"开业率" |
| 成本率 | 运营成本 ÷ 营业收入；是否含折旧与财务费用 | 不含折旧的成本率永远好看 |
| 回本周期 | 静态（投资÷年净现金流）还是动态（含折现） | 混用两种口径对比 |
| 转化率/捕获率 | 本项目客流 ÷ 明确界定的客源池 | 客源池大小随意取 |

> **报告中每个指标首次出现时，都必须写出它的口径。**

## 四、基准区间与偏离幅度

### 4.1 区间输出

对每个指标，用**主样本**（★）计算：`最小值 — 中位值 — 最大值`。
不足 3 个主样本时：只给"参考值 + 样本不足说明"，**不得声称是"行业基准"**。

### 4.2 偏离幅度（必算）

```
偏离倍数 = 本项目假设值 ÷ 基准中位值
偏离幅度 = （本项目假设值 − 基准中位值）÷ 基准中位值 × 100%
```

判定参考（配合证据强度，不单独作为结论）：
- 在区间内 → 假设可接受
- 超出区间上界 **< 20%** → 需要解释（P2）
- 超出区间上界 **20%–50%** → 明显偏乐观，需下调或补强论证（P1）
- 超出区间上界 **> 50%** 或 **> 2 倍** → 假设不可信（P0/P1，视其对结论的影响而定）
- 低于区间下界 → 也要提示（可能低估收入，也可能是项目本身条件更差，需说明）

> 这些百分比是**审查提示阈值**，不是行业标准值；报告中须注明"阈值为审查工具设定"。

### 4.3 呈现格式

| 指标 | 方案假设 | 基准区间（主样本） | 中位值 | 偏离幅度 | 判定 |
|---|---|---|---|---|---|
| 年客流 | 300 万人次 | 80–150 | 110 | +173% | 超出上界 1 倍以上，P0 |
| 人均消费 | 200 元 | 90–160 | 125 | +60% | 明显偏乐观，P1 |

## 五、对标失效怎么办

出现以下情况时，**不许凑数**，按此处理：

| 情况 | 处理 |
|---|---|
| 找不到同类型样本 | 降一级用"近似类型"+ 明确说明类比风险；该项结论降为"有条件成立" |
| 只有 1–2 个样本 | 给"参考值"，不给区间，不称"基准" |
| 数据只有 C 级 | 两源交叉后可用，但结论置信度降级；在《取证局限说明》列出 |
| 完全无公开数据 | **写"证据不足，暂不判定"**，把该数据项列入《待补数据清单》 |

## 六、识别方案里的"对标作弊"

审筑策的对标表时，专门查这几手：

1. **只挑最好的比**：全是成功案例，没有失败案例
2. **只挑最近的比**：全是近两年开业的首年爆发数据
3. **只挑大的是比**：拿全国标杆衬托自己"保守"
4. **偷换口径**：用别人的"全域人次"比自己的"购票人次"
5. **无出处的精确**：给出"某项目年客流 327 万人次"这种精确到个位却无来源的数字
6. **对标结论不进测算**：对标表做得很漂亮，但收益测算里的假设完全没参考它
