# 审查清单 · 产业园区册

适用于：经开区／高新区内的园中园、专业化产业园（生物医药、集成电路、新材料、软件信息）、标准厂房与研发办公、孵化器与加速器、物流仓储园。

与商业册最大的差别：**核心不是客流也不是租金，而是招商可实现性与载体适配**——盖得出来只是及格，招得进来才算成立，亩均产出说得过去才敢报政府。产业园区最容易犯的错是**用商业地产的算法做产业地产**：先算租金回报，再倒推客群，结果客群不存在。

---

## A. 产业选择与市场（YQ-A）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| YQ-A1 | 主导产业选择 | 产业方向与本地产业基础、资源禀赋无关（哪个热做哪个） | P0 |
| YQ-A2 | 产业链环节 | 只说产业门类，不说做哪个环节（研发／中试／制造／总部） | P0 |
| YQ-A3 | 企业客群画像 | 未说明目标企业的规模、阶段、来源地、迁移动机 | P0 |
| YQ-A4 | 区域竞争 | 未统计周边同类园区的存量载体、租金、去化 | P0 |
| YQ-A5 | 政策依赖度 | 结论主要靠补贴与税收返还支撑，政策一变即不成立 | P0 |
| YQ-A6 | 市场容量 | 目标企业数量按全国总量估算，未落到可触达范围 | P1 |

## B. 载体产品与配比（YQ-B）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| YQ-B1 | 载体类型配比 | 厂房／研发／中试／办公／配套比例无依据 | P0 |
| YQ-B2 | 层高荷载 | 按普通办公标准设计却招制造业；层高、荷载、柱距不匹配 | P0 |
| YQ-B3 | 厂房可分可合 | 单元面积固定，无法适配不同规模企业 | P1 |
| YQ-B4 | 特殊需求 | 环评、危化、蒸汽、冷冻、大功率用电、废气废水处理未预留 | P1 |
| YQ-B5 | 配套比例 | 宿舍、食堂、商业配套面积与实际就业人数脱节 | P1 |
| YQ-B6 | 容积率与强度 | 为凑指标做高层厂房，实际产业用不上 | P1 |
| YQ-B7 | 土地年限与分割 | 工业用地年限、能否分割转让、是否允许销售未说清 | P1 |

## C. 招商与企业客群（YQ-C）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| YQ-C1 | 招商漏斗 | 只有目标企业名单，没有触达路径与转化节奏 | P0 |
| YQ-C2 | 去化假设 | 开园即 80% 入驻；无爬坡期（一般 3–5 年） | P0 |
| YQ-C3 | 龙头企业 | 全靠一两家链主撑场，未评估其落地确定性 | P0 |
| YQ-C4 | 租金水平 | 租金高于周边同类园区却无差异化理由 | P0 |
| YQ-C5 | 免租与补贴 | 招商政策成本未计入测算 | P1 |
| YQ-C6 | 退出与腾退 | 无企业退出机制与低效用地处置安排 | P1 |
| YQ-C7 | 政府代建与定制 | 定制厂房的比例与风险承担方未明确 | P1 |

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| YQ-D1 | 收入结构 | 只有租金，无服务、能源、停车、增值服务收入 | P1 |
| YQ-D2 | 运营成本 | 缺物业、能源、安保、公共平台维护 | P0 |
| YQ-D3 | 公共服务平台 | 检测、中试、共享设备是否建、谁付费，未说清 | P1 |
| YQ-D4 | 亩均产出 | 未给亩均投资强度、亩均税收、亩均产值的预估 | P0 |

| ID | 检查项 | 提示信号 | 默认档 |
