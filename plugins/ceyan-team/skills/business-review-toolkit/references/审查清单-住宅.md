# 审查清单 · 住宅册

适用于：刚需／改善型住区、高层与洋房、别墅与低密、城市更新中的回迁安置房、租购并举中的租赁住房。

与商业册、文旅册最大的差别：**核心不是客流、也不是租金，而是去化速度与价格带**——卖得掉、卖得上价、卖得完，三条缺一条就不成立。住宅是所有类型里"数字最容易被做得好看"的一类，因为价格、去化率、成本三项都能单独调。

---

## A. 市场与客群（ZZ-A）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| ZZ-A1 | 客群界定 | 只说"改善客群"不说家庭结构、年龄段、现有住房与置换动机 | P0 |
| ZZ-A2 | 支付力测算 | 用城市均价×面积倒推总价承受力，不看本地实际成交结构 | P0 |
| ZZ-A3 | 客群来源 | 未区分本地内生需求与外来导入；未说明外来人口的就业支撑 | P1 |
| ZZ-A4 | 竞品供给 | 未统计同板块 2–3 年内的新增供应与库存去化周期 | P0 |
| ZZ-A5 | 板块能级 | 把规划利好当既成事实（地铁未通、学校未建就按已兑现溢价） | P0 |
| ZZ-A6 | 人口趋势 | 未看本地常住人口与出生率的走向，直接按历史去化推未来 | P1 |

## B. 产品与定位（ZZ-B）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| ZZ-B1 | 定位与支付力匹配 | 定位改善但主力总价段超出板块支付力上限 | P0 |
| ZZ-B2 | 户型配比 | 户型段与客群结构不匹配（三房为主却主打两口之家） | P1 |
| ZZ-B3 | 面积段与得房率 | 用建筑面积讲卖点，不谈得房率与赠送口径 | P1 |
| ZZ-B4 | 产品同质化 | 户型、立面、景观与周边竞品高度重合，无差异点 | P1 |
| ZZ-B5 | 配套兑现 | 教育、商业、交通配套的兑现时间未说清，按已建成计价 | P0 |
| ZZ-B6 | 精装标准 | 精装单价与售价的关系不清；装标是否计入成本、能否支撑溢价 | P1 |
| ZZ-B7 | 车位与配建 | 车位配比与去化假设脱节；配建面积未计入可售比 | P1 |

## C. 价格与去化（ZZ-C）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| ZZ-C1 | 价格取值 | 用板块最高价或二手房挂牌价定售价，未看实际成交 | P0 |
| ZZ-C2 | 去化速度 | 月均去化按理想值假设，无同板块可比项目对照 | P0 |
| ZZ-C3 | 去化周期 | 总货量与去化速度不匹配，未说明清盘时间 | P0 |
| ZZ-C4 | 价格策略 | 首开与后续批次的价格梯度无依据；未考虑以价换量 | P1 |
| ZZ-C5 | 蓄客与转化 | 认筹量、转化率无依据；未说明渠道依赖度 | P2 |
| ZZ-C6 | 政策扰动 | 限价、限购、限贷、预售资金监管的变化未做情景 | P1 |
| ZZ-C7 | 剩余货值 | 未说明尾盘与滞销户型的处置方式 | P2 |

## D. 成本与利润（ZZ-D）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| ZZ-D1 | 土地成本口径 | 楼面价是否含契税、配套费、拆迁补偿；口径与同业不一致 | P0 |
| ZZ-D2 | 建安成本 | 明显低于同区域同类产品；未区分地上地下、装修标准 | P0 |
| ZZ-D3 | 期间费用 | 缺管理费、销售费、财务费用，或按极低比例计提 | P0 |
| ZZ-D4 | 税费 | 土增税、增值税、所得税的处理方式未说明 | P1 |
| ZZ-D5 | 利润率口径 | 净利率、IRR、ROE 混用；分子分母口径不一致 | P1 |
| ZZ-D6 | 敏感性 | 无"售价下浮 10% / 去化延长一年"的情景 | P0 |

## E. 政策与合规边界（ZZ-E）

> **本节只提建议，不做判定。** 合规与否由法务与主管部门定，验筹只提示"这里可能有问题、去问一下"。

| ID | 检查项 | 提示信号 | 默认档 |
|---|---|---|---|
| ZZ-E1 | 用地性质与年限 | 住宅、商住、租赁住房的年限与分割销售限制是否说清 | P1 |
| ZZ-E2 | 保障房配建 | 配建比例、移交方式、是否计入可售面积 | P1 |
| ZZ-E3 | 预售条件 | 预售节点、资金监管、形象进度要求 | P1 |
| ZZ-E4 | 规划指标 | 容积率、限高、日照、绿地率是否已核 | P1 |
| ZZ-E5 | 学区承诺 | 是否出现"学区房"式承诺（高风险表述） | P0 |
