# 审查清单 · 城市更新册

适用于：老旧街区/厂区/市场改造、拆除重建、整治提升、历史地段活化。
与文旅/商业两册最大的差别：**核心变量是土地与拆迁成本、资金平衡、合规约束**——很多更新项目不是"经营不成立"，而是"钱一开始就不平衡"。

---

## A. 现状与产权（CS-A）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| CS-A1 | 现状问题诊断 | 未说清为什么必须更新（安全/业态衰退/资产低效），直接上方案 | P0 |
| CS-A2 | 房屋与土地权属 | 权属不清、多方共有、抵押未解除，却假设可整体改造 | P0 |
| CS-A3 | 租赁关系 | 既有租户清退成本、补偿标准、纠纷风险未计 | P1 |
| CS-A4 | 建筑安全 | 未做结构安全评估即确定功能与荷载 | P1（提示） |
| CS-A5 | 历史保护要求 | 涉及历史建筑/风貌保护，方案未对应限制条件 | P1（提示） |
| CS-A6 | 居民意愿 | 涉及居民安置，未说明意愿与安置方案 | P1（提示） |

## B. 政策与规划（CS-B，浅审为主）

| ID | 检查项 | 提示内容 |
|---|---|---|
| CS-B1 | 控规与用地性质 | 拟设功能是否与控制性详细规划一致；需调整的，路径与周期是否可行 |
| CS-B2 | 容积率与限高 | 是否有提升空间；已按提容测算的，须核实程序能否走通 |
| CS-B3 | 更新政策适用性 | 是否纳入更新单元/项目库，可享受哪些政策 |
| CS-B4 | 审批链条 | 立项、规划许可、施工许可、消防、环评等前置条件 |
| CS-B5 | 生态与红线 | 河道蓝线、绿地、文保、军事等限制 |

> 本册的政策部分**只提示、不下结论**，最终由法务与规划专业判断。

## C. 资金平衡（CS-C，本册核心）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| CS-C1 | 拆迁/征收成本 | 用估算单价代替实际补偿标准；未含过渡安置费与时间成本 | P0 |
| CS-C2 | 土地成本 | 未说明土地取得方式与成本（划拨/出让/作价出资） | P0 |
| CS-C3 | 改造投资强度 | 元/㎡ 改造投资显著低于同类更新项目 | P1 |
| CS-C4 | 资金平衡逻辑 | 靠"经营性收入覆盖全部投资"但项目本身是公益属性 | P0 |
| CS-C5 | 可售/可租比例 | 可售面积测算无规划依据；可售比过高依赖住宅销售回款 | P1 |
| CS-C6 | 跨期平衡 | 一期投入大、回收慢，二三期回款能否支撑一期缺口，未见现金流衔接 | P1 |
| CS-C7 | 政府补贴与专项资金 | 假设获得补贴但未核实政策口径与额度 | P1 |
| CS-C8 | 时间成本 | 拆迁、审批周期按理想值估算；未计资金占用成本 | P1 |
| CS-C9 | 失败情景 | 无"拆迁延期/销售不畅"下的应对 | P2 |

## D. 功能与运营（CS-D）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| CS-D1 | 新功能与区位匹配 | 老城区位做需要大客流的文旅目的地叙事 | P1 |
| CS-D2 | 公益与经营配比 | 公共空间占比过高但无运营补贴来源 | P1 |
| CS-D3 | 社区关系 | 更新后与原住民/原业态关系断裂，导致活力流失 | P2 |
| CS-D4 | 运营主体 | 只做建设不做运营安排，或运营方无同类经验 | P1 |
| CS-D5 | 长期维护 | 公共空间与设施的长期维护费用无来源 | P2 |
| CS-D6 | 业态可招性 | 老城区的租金承受力与目标业态不匹配 | P1 |

## E. 交叉适用

| 情况 | 追加加载 |
|---|---|
| 更新后主要做文旅/街区 | 追加 `审查清单-文旅综合体.md` 的 A/C/D 节 |
| 更新后主要做商业 | 追加 `审查清单-商业综合体.md` 的 A/C/D 节 |
| 更新后主要做产业/办公 | 追加通用骨架：产业客源、租金承受力、去化周期 |
