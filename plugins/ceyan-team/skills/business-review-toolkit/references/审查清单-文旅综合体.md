# 审查清单 · 文旅综合体册

适用于：文旅小镇、文旅商业综合体、景区配套商业、城市文旅街区（存量改造型）、微度假目的地。
每项给出「检查什么 / 不合格信号 / 默认档位」。**默认档位仅供参考，最终档位须结合证据与影响面判定，并经用户确认。**

---

## A. 客源与市场基础（LY-A）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| LY-A1 | 区域客源总量是否用对口径 | 用"全域旅游人次"直接做项目客流基数，未剔除过境、未剔除重复计算 | P1 |
| LY-A2 | 过夜游客量是否单独取出 | 二消与住宿测算建立在总游客量上，未看过夜率 | P0 |
| LY-A3 | 客源半径与结构 | 未说明本地/省内/省外占比；或占比与区位条件明显冲突 | P1 |
| LY-A4 | 区域客流趋势 | 假设增速高于统计公报实际增速且无解释；或引用三年前数据当现状 | P1 |
| LY-A5 | 团散比 | 团客按散客票价结算（或反之），未区分返点与团餐 | P1 |
| LY-A6 | 淡旺季结构 | 测算按全年平均，无月度分布；淡季无内容填充方案 | P0 |
| LY-A7 | 捕获率论证 | 只写"预计可分流 X%"，无依据、无同类对标 | P0 |
| LY-A8 | 竞品分流 | 只列竞品数量不评分流强度；或竞品已饱和仍假设增量 | P1 |
| LY-A9 | 新增供给 | 未查同城在建/拟建同类项目，未来分流未计入 | P2 |
| LY-A10 | 虚假市场结论 | 出现"必然火爆""市场空白"等无据判断 | P2 |

## B. 定位与主题（LY-B）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| LY-B1 | 推导链连续性 | 定位与前面的区位/市场/客群分析脱节，中间缺环 | P0 |
| LY-B2 | 定位是否有取舍 | 既要亲子又要康养又要研学又要夜经济，客群互斥 | P1 |
| LY-B3 | 差异化真实性 | 定位可被竞争者一句话复制（"打造XX文化体验目的地"） | P1 |
| LY-B4 | 定位与体量匹配 | 小体量承载"国家级/世界级"叙事 | P1 |
| LY-B5 | 主题与在地文化的关系 | 文化符号贴在表面，未转化为产品（有雕塑无体验） | P2 |
| LY-B6 | 定位可落地性 | 定位转化不出空间、业态、产品清单 | P1 |
| LY-B7 | 与上位规划的关系 | 定位与城市/景区总体规划确定的功能定位冲突 | P1（提示） |

## C. 产品与业态（LY-C）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| LY-C1 | 业态与客群一致性 | 本地复购客群配一次性打卡业态；或外来客群配社区刚需业态 | P0 |
| LY-C2 | 引流/变现/配套比例 | 无核心吸引物（纯商业拼盘）；或全免费无变现；或配套严重不足 | P1 |
| LY-C3 | 主力业态可招商性 | 依赖区域不存在的品牌/品类；无备选品牌 | P1 |
| LY-C4 | 面积配比与体量 | 业态数量过多、单店面积过小，无法运营 | P1 |
| LY-C5 | 二消场景支撑 | 人均消费假设找不到对应的消费点位（无餐饮/无零售/无体验项目） | P0 |
| LY-C6 | 内容与运营能力 | 需要持续内容生产（演艺/研学/活动），但无团队与预算 | P1 |
| LY-C7 | 季节适配 | 冬季/雨天无室内业态承接，全年营业假设不成立 | P1 |
| LY-C8 | 住宿产品匹配 | 有住宿但未论证谁会住、住几晚、房价凭什么 | P1 |
| LY-C9 | 亲子/研学等专项 | 未考虑安全、资质、教育内容供给 | P2 |
| LY-C10 | 与竞品重复度 | 业态与同城竞品高度重合且无差异 | P1 |

## D. 收益模型（LY-D）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| LY-D1 | 门票政策口径 | 收费/免费未定，却已按收费测算；或政策要求免费开放仍算门票收入 | P0 |
| LY-D2 | 人均消费构成 | 只有总额，无门票/餐饮/零售/体验/住宿拆分 | P1 |
| LY-D3 | 收入爬坡 | 开业首年即按成熟年客流测算 | P1 |
| LY-D4 | 增长率假设 | 连续正增长，无区域趋势支撑；或超过区域大盘增速却无解释 | P1 |
| LY-D5 | 非经营性收入占比 | 补贴/上级拨款/地产销售占比过高但无实现路径 | P0 |
| LY-D6 | 收入与承载匹配 | 客流 × 客单价超出经营面积、餐位、床位可承载上限 | P1 |
| LY-D7 | 分业态收入加总 | 各业态收入加总 ≠ 总收入；或与面积配比矛盾 | P1 |
| LY-D8 | 单价合理性 | 票价/房价/餐价偏离同城同类基准 | P1 |

## E. 成本与运营（LY-E）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| LY-E1 | 运营成本完整性 | 缺人力、能耗、维护、营销、招商佣金、税费中的任一项 | P0 |
| LY-E2 | 成本率合理性 | 成本率显著低于同类项目且无解释 | P1 |
| LY-E3 | 人力配置 | 未按客流与服务标准配人；或人力成本按极低值估算 | P1 |
| LY-E4 | 能耗（季节性） | 未考虑采暖/制冷峰值与淡季固定成本 | P2 |
| LY-E5 | 营销费用 | 无持续营销预算，或按一次性投入计 | P1 |
| LY-E6 | 折旧与财务费用 | 不计折旧，或不计贷款利息 | P1 |
| LY-E7 | 更新改造准备金 | 长周期运营无翻新预算 | P2 |
| LY-E8 | 淡季现金流 | 无月度现金流表，看不到最低点与缺口 | P1 |
| LY-E9 | 运营主体 | 未说明谁来运营、有无同类项目经验、管理费怎么算 | P1 |

## F. 投资与资金（LY-F）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| LY-F1 | 投资与面积/造价的勾稽 | 投资额 ÷ 改造面积 显著低于同类改造单价 | P1 |
| LY-F2 | 投资口径 | 含不含土地/租金/软性投入（内容、IP、开办费）不明 | P1 |
| LY-F3 | 回收期口径 | 静态动态混用；未说明是否含建设期 | P1 |
| LY-F4 | 回收期合理性 | 回收期显著短于同类项目且无独特优势支撑 | P0 |
| LY-F5 | 资金来源 | 只说总投资，不说钱从哪来、资金成本多少 | P1 |
| LY-F6 | 分期与测算匹配 | 分期建成，测算却从第一年按全量计 | P1 |
| LY-F7 | 敏感性分析 | 无客流/客单价/成本三因素的下行情景 | P1 |
| LY-F8 | 退出与兜底 | 无失败情景下的处置方案（谁承担、怎么退） | P2 |

## G. 政策与合规（浅审，仅提示）

| ID | 检查项 | 提示什么 |
|---|---|---|
| LY-G1 | 用地/用房性质是否支持拟设业态 | 提示交法务/规划核实，不下结论 |
| LY-G2 | 文物保护、生态红线、林草、水利等限制 | 提示可能存在审批前置条件 |
| LY-G3 | 门票与收费政策（政府定价/免费开放要求） | 提示需核价 |
| LY-G4 | 消防、特种设备（演艺/游乐设施） | 提示需专项审批 |
| LY-G5 | 招商与经营的资质要求（餐饮、住宿、演出） | 提示证照成本与周期 |

## H. 存量改造专项（LY-H，适用于既有建筑重新包装）

| ID | 检查项 | 不合格信号 | 默认档 |
|---|---|---|---|
| LY-H1 | 现状诊断 | 未说清现状为何不成功（是位置、产品、运营还是资金），就直接给新主题 | P0 |
| LY-H2 | 改造 vs 重建的经济性 | 未比较改造与重建的成本与效果 | P1 |
| LY-H3 | 既有建筑的适配性 | 层高、柱网、荷载、机电容量能否承载新业态 | P1 |
| LY-H4 | 改造期经营 | 分期改造期间的停业损失与现金流未计 | P2 |
| LY-H5 | 既有租约与商户 | 老商户清退成本与纠纷未计 | P2 |
| LY-H6 | 资产权属 | 产权/租赁关系是否清晰，改造权是否具备 | P1（提示） |
