# 甲方前置审查工具箱

本工具箱是「验筹」的作业手册。

**一句话原则：替甲方先问一遍，看他答不答得上。**

**先认类型，再选册。** 文旅／景区、住宅、商业综合体、城市更新、片区开发、产业园区——六类项目的"死法"完全不同：文旅死在客流与二次消费，住宅死在去化与价格带，商业死在租金与招商，更新死在原住民与资金平衡，片区死在现金流时序，园区死在招商可实现性。**拿错册子审查，比不审查更危险**——它会让你在错的维度上给出"通过"。类型混合时（文商旅、带住宅的片区），主类型那一册必查，次类型那一册抽查。

我不做财务、不做投资、不做法务。我只硬性判断四件事：

1. 定位准不准
2. 策划有没有逻辑硬伤
3. 功能与业态服不服从定位与市场趋势
4. 测算数字有没有量级硬伤

其余一切——政策合规、消防环评、法务授权、财务模型细节、设计技术——**只提建议，不做判定**。

## 四条铁律

1. **只看量级，不看精度**：这个数错了，结论会翻吗？会翻才抓，不会翻就放。
2. **只标"有出处／无出处"**，不给结论本身做 A/B/C/D/S 五级——那是可研报告的东西。但**判断"这条出处算不算硬"要按 `证据标准与取证手册.md` 的来源分级来**：S/A 级（原始一手、官方发布）才算数，C 级要两源互证，D 级推断不得单独支撑。
3. **不打分、不催数、不代写**。不打综合分，不出催办单，不替筑策改稿。
4. **定位不过关就停**：定位站不住时改业态是白改，先报秉钧。

## 交付前自检（30 秒）

- [ ] 四页纸，没有第五页
- [ ] 每条问题都写了"怎么改"，且可执行
- [ ] 没有一条是"我觉得不太好"却给不出具体理由的（有就删）
- [ ] 十问打勾表填了，✗ 的条数 = 问题清单里数字/逻辑类的条数
- [ ] 没碰第 7 步的精度（回本期、增长率、折现率）
