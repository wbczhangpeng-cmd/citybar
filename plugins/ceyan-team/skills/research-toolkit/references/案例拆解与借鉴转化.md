# 案例拆解与借鉴转化

案例章是整份研究最容易被写废的一章。写废的方式只有一种：**用同一个框架把 10 个案例套一遍，然后得出 10 条谁都能说的结论。**

本文件的核心规矩只有一句：

> **不设统一维度、不做横向对比。** 每个案例成功的原因各不相同，一个案例一套归因。

---

## 一、选样三关（三关全过才进库）

| 关 | 判据 | 怎么当场判 |
|---|---|---|
| **第一关·时效** | 2021 年后开业或爆红为主 | 开业年 / 爆红年份可查（官网、政府新闻、平台首个爆款笔记时间）。允许 1–2 个更早标杆，但必须在卡片里写一句「为什么它至今仍有效」（如：仍是该品类全国客流第一、模式被近三年新项目复制） |
| **第二关·代表性硬指标 ≥2 项** | 客流／营收／平台热度榜／获奖或入选名单／媒体报道量／复游率，**至少两项且每项能给出处** | 逐项填数字 + 出处。填不出出处的项按 0 计，不许拿「据说很火」凑数 |
| **第三关·业内公认** | 被行业内部当作案例，而不只是被游客知道 | 下列四条**满足任一**即可，但必须写明是哪一条、证据是什么：① 入选国家级/省级示范、试点、典型案例名单；② 被 ≥2 家独立专业媒体或行业报告**单列成节分析**（不是顺带提及）；③ 在其品类的同城/同区域平台榜单长期前 10（连续在榜 ≥3 个月）；④ 有从业者、研究者或操盘方公开发表的复盘文章/演讲 |

**第二关与第三关是「且」的关系，不是「或」。** 数据漂亮但业内没人当案例的（网红打卡点、开业三个月的爆款），不选；业内口碑好但拿不出两项硬指标的（小众标杆），也不选——写进《取证局限》，不要硬凑。

### 选样配额

| 项 | 数量 | 说明 |
|---|---|---|
| 成功案例 | 8–12 个 | 同一细分品类不超过 3 个，避免变成同一类项目的复读 |
| 失败案例 | 2–3 个 | 必须与成功案例处在**同一决策场景**（同类区位条件或同类投资量级），否则没有对照意义 |
| 更早标杆 | ≤2 个 | 占成功案例名额，不额外增加 |

## 二、单案例卡片模板

一个案例一张 md 卡片，字段固定，缺项写「未取得」并进《取证局限》。

```
### 案例 C-03｜〈案例名〉

- 地点：〈省·市·区〉
- 开业/爆红：YYYY 年 MM 月（爆红指平台热度突变的月份）
- 类型：〈按本品类口径，一句话〉
- 体量：占地 __ 亩 / 建面 __ ㎡ / 投资 __ 亿元 / 年客流 __ 万人次
- 操盘方：〈公司或政府平台〉（可查则写，查不到写未取得）
- 证据配置：A×2 B×3 C×1（列出编号，对应台账）
- 入样理由：硬指标①__（出处） ②__（出处）；业内公认：第__条（证据）

**成功点（≥3 条，每条=具体做法+证据）**
1. 做法：…… → 结果：……（量化）｜出处：……
2. 做法：…… → 结果：……（量化）｜出处：……
3. 做法：…… → 结果：……（量化）｜出处：……

**关键转折**：哪一年、因为什么动作，客流/收入出现台阶式变化（有则写，无则写「未观察到明显转折」）

**可复用动作**：从上面成功点里挑出「换到别的项目也成立」的那 1–2 条
**不可复用条件**：依赖独占资源的部分（独家 IP、独家地块、财政兜底、特殊政策窗口）

**出处清单**：编号 + 链接 + 获取日期
```

### 成功点写法：合格 / 不合格

| 不合格 | 为什么废 | 合格 |
|---|---|---|
| 定位准确，抓住了年轻客群 | 无动作、无证据、无法证伪 | 把主入口动线从 300 米缩到 80 米，首店集中在前 50 米，2024 年进店转化率从 12% 提到 27%（来源：操盘方 2024 公开复盘演讲） |
| 运营良好，体验感强 | 形容词，不构成信息 | 淡季每周换一次主题市集，全年 48 场，淡季（11–3 月）客流占全年比重从 18% 升至 31%（来源：当地文旅局 2024 年度通报） |
| 媒体宣传到位 | 同义反复 | 开业前 90 天在本地生活平台投放 3 轮达人探店（共 120 位），开业首月抖音同城景点榜连续 4 周第 1（来源：平台榜单截图，B 级仅热度参照） |

判据只有一条：**把这句话的主语换成任意另一个项目，它还成立吗？** 成立就是空话，删掉重写。

## 三、归因候选清单（提示用，不是必填）

下面十四项是**提问用的提示清单**，帮你想「这个案例凭什么成」。它不是评分表，不是每个案例都要填满，更不是必须逐项排查的维度。

| 候选归因 | 该问的问题 |
|---|---|
| 区位交通 | 离主城/主景区/高铁站多少分钟？停车位多少？是不是顺路 |
| 客群定位 | 主打谁的哪一段空闲时间？工作日和周末是不是两拨人 |
| 空间组织 | 动线长度、停留节点、视线通廊怎么排的 |
| 功能业态 | 主力业态是什么、占比多少、有没有「非来不可」的那一个 |
| 营销策划 | 开业前做了什么、有没有事件、投放节奏如何 |
| 主题选择 | 主题是本地独有的，还是可以搬走的 |
| 媒体宣传 | 谁先报道的、是自然传播还是投放 |
| 政策窗口期 | 有没有踩中补贴、试点、专项债、节庆 |
| 投资强度 | 单方投资多少、有没有为「出片」超配 |
| 票价与客单 | 门票/免费策略、二次消费占比 |
| 内容迭代机制 | 多久换一次内容、由谁负责、预算从哪来 |
| 在地文化独占性 | 这个文化元素别人能不能用 |
| 渠道分销 | 谁在卖票、OTA 抽成、旅行社/研学渠道占比 |
| 操盘团队 | 团队此前做过什么、有没有同类经验 |

**允许写清单外的原因。** 真实世界里经常是「甲方有一块别人拿不到的地」或者「一把手任期刚好覆盖建设期」这种不上台面的原因——只要能给证据，照写。反过来，清单里的项如果查不到证据，**宁可空着，不许编**。

## 四、失败案例卡片（只拆「死在哪一步」）

不做五维展开，不做失败原因罗列。只回答一个问题：它在哪一步上错了，错成什么样。

步骤链条固定五步，定位到**最靠前的那一步**：

```
立项与选址 → 投资与体量 → 内容与产品 → 获客与渠道 → 现金流与运营
```

```
### 失败案例 F-02｜〈案例名〉

- 地点 / 开业 / 停业或重整时间：……
- 体量：投资 __ 亿元，占地 __ 亩，年客流峰值 __ 万人次
- **死在第几步**：第 2 步「投资与体量」
- 具体表现：单方投资 __ 元/㎡，为同城同类的 __ 倍；年客流需达 __ 万人次才保本，实际峰值 __ 万人次（缺口 __%）
- 证据：〔出处 + 日期 + 级别〕
- 一句警示：对本项目的含义——〈一句话，指向可检查的动作，不写「要引以为戒」〉
```

失败案例的价值在**缺口百分比**和**保本门槛**这两个数。拿不到这两个数，这个案例就不写——写了也只是情绪。

## 五、《借鉴清单》：唯一做归并的一层

前面所有案例各自归因，互不比较。**只有在这一层才做合并去重**，因为下游要的是「我该改什么动作」，不是「别人有多好」。

### 三段式模板

| 编号 | 别人的做法（案例 + 出处） | 我们该改哪个动作 | 验收标准 |
|---|---|---|---|
| B-01 | C-03 把首店集中在前 50 米，进店转化 12%→27%（出处：操盘方 2024 复盘）｜C-07 主入口与停车场间设 60 米商业街，非门票收入占 41%（出处：当地文旅局通报） | 把主入口到核心区的第一段动线，改为「先过 3 个可消费节点再进场」，节点业态按停留 3–5 分钟设计 | 方案图上前 80 米内出现 ≥3 个独立消费点；开业后首段动线停留时长 ≥3 分钟（以客流热力或闸机分段数据验证） |
| B-02 | C-05 淡季每周换主题市集，淡季占比 18%→31%（出处：年度通报） | 把「一季一活动」改为「一季一主题、一周一市集」，并指定内容负责人与单场预算 | 排期表覆盖全年 ≥40 场；淡季（11–3 月）客流占比目标值写入运营 KPI |

### 去重归并规则

1. **同一动作、不同案例 → 合并一条，出处并列。** 合并后仍要保留每个案例的具体数字，不要压成「多个案例均显示」。
2. **动作相似但触发条件不同 → 不合并，拆两条**，并在「别人的做法」里写清适用条件（如「仅适用年客流 >100 万人次」）。
3. **一条只对应一个动作。** 一句话里出现两个动作（「既要缩动线又要做夜游」）就拆开。
4. **落不到单一动作的，丢弃。** 「重视内容运营」「强化 IP」这类无法变成动作的，一律不进清单——它们进不了验收。
5. **验收标准必须可测**：出现数字、出现检查对象、出现验证方式。写「明显改善」的不合格。
6. **条数收敛在 12–20 条。** 超过 20 条说明没有归并，只是把案例抄了一遍；少于 12 条说明案例读得不够。

### 禁止清单

- 不做案例打分、不排序、不做雷达图、不做「维度 × 案例」矩阵
- 不写「综合各案例经验」「取长补短」这类没有动作的过渡句
- 不把「不可复用条件」写进借鉴清单——那些属于案例卡片，不属于动作
