# 报告骨架与写作铁律

本文件管两件事：**每一章必须有什么**，以及**哪些话不许写**。

正文总量 1.2–1.8 万字（不含附录、台账、卡片）。低于 1.2 万说明证据不够，高于 1.8 万说明没收敛。

---

## 一、六章配比与必含项

| 章 | 必含项（缺一即不合格） | 字数 | 占比 |
|---|---|---|---|
| 前置·摘要页 | 见第三节，≤600 字 | ≤600 | 另计 |
| ① 研究命题与范围 | 命题一句话；要回答的 3–5 个具体问题；空间范围（半径或行政区）；时间范围与资料截止日；**不研究什么** | 1,000–1,400 | ~8% |
| ② 政策（国/省/市三层） | 每层条数下限：国 10–20、省 8–20、市 8–20；**按红线/可争取/背书重组**；政策窗口期小节（近 3 年到期或新出） | 2,800–3,600 | ~22% |
| ③ 上位规划与合规约束 | 总规/控规/专项规划各自的约束条款；用地性质与强度指标（容积率、限高、绿地率、退线）；审批链条（谁批什么、先后顺序）；6–10 条硬约束清单 | 1,600–2,200 | ~13% |
| ④ 案例 | 成功 8–12 + 失败 2–3；每案一卡片；末段《借鉴清单》12–20 条三段式 | 3,600–5,000 | ~30% |
| ⑤ 市场与客群 | 大盘（客流/收入/增速，三源）；客源结构（地域/出行方式/停留时长/人均花费）；竞品供给表；季节性曲线；需求缺口 | 1,800–2,400 | ~15% |
| ⑥ 启示与建议 + 取证局限 | 定位/业态/运营三段建议，每条带依据；取证局限四段 | 1,400–2,000 | ~12% |

## 二、政策章：按判定重组，不按时间罗列

罗列政策是这一章最典型的废法——读者拿不到任何可操作结论。重组方式固定为三栏：

| 判定 | 定义 | 每条必须写 |
|---|---|---|
| **红线** | 明确禁止或严格限制，动了就出局 | 文号 + 条款原文摘句（≤30 字）+ 具体禁止什么 + 越线后果（罚则/不予审批） |
| **可争取** | 有弹性空间，需走程序或满足条件 | 文号 + 弹性点在哪句 + 争取路径（找谁、报什么、需什么材料）+ 成功先例（有则写） |
| **背书** | 可作为叙事、申报、争取资源的依据 | 文号 + 可引用的表述 + 适用场景（申报哪个专项/写进哪段叙事） |

三条纪律：

1. **每条都要有原文摘句**，不许只写文件名。摘句控制在 30 字内，够支撑判定即可。
2. **红线必须写后果**，只写「受限」等于没说。
3. **政策窗口期单独一节**：列近 3 年内到期、修订、或新出台的文件，说明「现在做和两年后做有什么不同」。这是政策章唯一有前瞻价值的部分。

配套 `政策清单.csv` 九列固定：发文机关／文号／标题／发布日期／施行期／效力层级／现行有效性／相关条款摘句／影响判定。CSV 里每条都要能在正文三栏中找到归属，找不到的就是没判过。

## 三、摘要页：≤600 字，只回答「改变了什么判断」

下游只看这一页。它不许是正文缩写，必须写成**判断的前后对比**。

四段结构，段段有硬要求：

```
### 一页结论

**结论**：〈一句话，含一个可核验的数或一个明确的方向判断〉

**这份研究改变了三个判断**
1. 原本以为 __，实际 __（依据：__，__ 级）
2. 原本以为 __，实际 __（依据：__）
3. 原本以为 __，实际 __（依据：__）

**三件必须现在决定的事**
1. __（不决定的后果：__）
2. __
3. __

**两件还不确定的事**
1. __（缺什么数据、谁能补）
2. __
```

判据：

- 「改变了三个判断」里如果有一条是「原本以为要研究、实际研究了」——删掉，那不是判断
- 每条对比后面必须挂级别标（A/B/C/D/S），一条挂不上就说明它只是印象
- **通篇不出现「建议进一步研究」「具有重要意义」「打造标杆」**
- 超过 600 字就砍第二段，不许砍第四段——不确定的事必须让下游知道

## 四、建议章：只给建议，不给定案

我的位置在第一棒。下游拿我的研究做定位判断，定案权在下游。所以建议章写成「三段 + 三条确认」：

```
### 6.x 对本项目的启示与建议

**建议一（定位）**：__
- 依据：〈指向前五章的具体条目〉
- 若采纳，下游需确认：① __ ② __ ③ __

**建议二（业态）**：……（同上三行）
**建议三（运营）**：……（同上三行）

> 以上为研究侧建议，最终方案由下游定案。本报告不对定案结果负责，只对建议所依据的事实与出处负责。
```

三条纪律：

1. **每条建议必须挂依据**，指不回前五章的，是拍脑袋，删。
2. **不写「应该定成 __」**，写「若定成 __，需先确认 __」。区别在于：前者替下游做了决定，后者把决定所需的前提交回去。
3. **不越界**：不做视觉、不做 PPT、不写汇报稿、不做投资测算、不做建筑方案。被要求时回一句「超出本棒范围」，不硬做。

## 五、写作铁律：禁用表述清单

| 禁用 | 为什么 | 改成 |
|---|---|---|
| 「随着 __ 战略的深入推进」 | 零信息量开头 | 直接写条款、数字或事实 |
| 「具有重要意义」「影响深远」 | 结论空转，无法检验 | 写对谁、什么意义、怎么验证 |
| 「打造 __ 新高地／标杆／样板」 | 口号，且无法验收 | 写目标客群 + 可比对象 + 量化目标 |
| 「深入分析」「综合考虑」「统筹兼顾」 | 不可执行 | 写用了什么方法、权衡了哪两项、结论偏向哪边 |
| 「据测算」「数据显示」（无出处） | 造假高发区 | 补出处 + 日期，补不上就删 |
| 「业内普遍认为」「行业惯例」 | 不可核 | 指名机构与报告，或标 D 级并说明不影响结论 |
| 「有望」「或将」+ 数字 | 用模糊词包装预测 | 写情形（乐观/中性/保守）+ 触发条件 |
| 「填补空白」「全国首创」「首个」 | 需证明穷尽检索 | 写比对范围 + 检索日期 + 检索式 |
| 「建议进一步研究」 | 把缺口推给下游 | 写清缺什么、谁能补、补了对结论有什么影响 |
| 「约」「左右」「大幅度」滥用 | 掩盖精度 | 写实际精度（保留几位）或说明区间来源 |
| 「不仅仅是 __，更是 __」 | 修辞代替论证 | 拆成两个可证伪的陈述 |
| 「值得关注的是」「不难发现」 | 过渡废话 | 删掉，直接写那一句 |

### 三条正面要求

1. **每段第一句是结论句**，不是背景句。读者只读每段首句也能读懂全文。
2. **一个数字只出现一种口径**，全文统一；换口径必须当段注明。
3. **推断句必须以「推断：」开头**，且同句内的数字另有出处。

## 六、交付前总检（5 分钟）

- [ ] 六章齐全，字数在 1.2–1.8 万区间，摘要 ≤600 字
- [ ] 政策 30–60 条，CSV 九列齐全，每条在正文三栏有归属
- [ ] 案例 8–12 成功 + 2–3 失败，成功案例每案 ≥3 条「做法+证据」
- [ ] 《借鉴清单》12–20 条，每条三段式，验收标准含数字或检查对象
- [ ] 每个数字都能在台账指到行；指不到的已删
- [ ] 全文搜一遍禁用表述清单，命中即改
- [ ] 政策章没有按时间罗列；建议章没有替下游定案
- [ ] 取证局限写了具体检索式与日期，不是「多方查找未果」
- [ ] 全文无具体项目名泄漏进示例（示例一律中性化）
