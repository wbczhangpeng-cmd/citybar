# 样张产出规范

样张是你唯一的"可验收凭证"。没有样张，用户只能凭文字想象，而想象中的方案永远比现实好看。

## 一、定位

**样张是规范的证明，不是成品。**

- 验证的是"这套规则排出来成不成立、好不好看"
- 不是验证"这页文案写得好不好"（那是淬言的活）
- 不是验证"这套图美不美"（那是落版与琢磨的活）

**所以：样张上必须有"样张 · 非成品"的标识**，避免被误当定稿继续往下传。

## 二、数量与覆盖

| 项 | 要求 |
|---|---|
| 数量 | 3–5 页 |
| 必须覆盖 | 至少 4 种页型 |
| 建议组合 | ① 结论大字页 ② 数据图表页 ③ 论点支持页（左文右图）④ 图版页（或技术图纸页）⑤ 封面（可选） |
| 其中一页 | 必须按"细"档做到底，让用户看到最细能细到什么程度 |

**不要用 5 页同一个页型**——那不叫样张，叫重复劳动。
**不要只做封面**——封面是最不容易翻车也最没有信息量的页。用户拿封面判断不了任何东西。

## 三、产出形态

| 形态 | 用途 | 何时用 |
|---|---|---|
| **SVG**（主） | 精确表达 hex、字号、间距、坐标 | 默认必出 |
| **PNG 预览** | 模板库缩略图、快速查看 | 必出，与 SVG 配套 |
| **Ardot 画布** | 可编辑，能当设计稿改 | 用户明确要求"样张要能改"时 |
| **真 pptx** | — | **不出**。一旦出 pptx，就分不清问题出在规范还是出在生成 |

## 四、SVG 画法约定

- `viewBox="0 0 1920 1080"`，与令牌画布一致
- 字体用 `font-family="Source Han Sans SC, PingFang SC, Microsoft YaHei, sans-serif"` 这种**带 fallback 的写法**，不要引 webfont
- 所有颜色写 hex，不写 rgb()，方便与令牌逐项对照
- **文字保持为 `<text>`，不转曲**（样张要能验证字号行高，转曲就验证不了）
- 图形用 rect / path / line / circle，**不嵌 base64 图片**（除图版页的图片占位）
- 每页加一个 `<g id="sample-badge">` 放"样张 · 非成品"角标，11px，中性第三阶，右下角
- 组内命名用语义 id（`title` / `chart` / `conclusion` / `footnote`），便于用户对照蓝图

## 五、图片在样张里怎么处理

- **有图**：用占位框 + 标签文字（如"意向图 · 黄昏院落水景"），不要拿无关网图凑
- **无图但需要**：占位框里写清五级标签与内容要点
- **禁止**：用渐变块假装图片、用图标堆砌假装视觉丰富

样张的图片是占位，这一点必须在交付说明里讲明，否则用户会以为图就这样。

## 六、命名与输出

```
<项目简称>/samples/
├── sample-01-conclusion.svg  + .png
├── sample-02-chart.svg       + .png
├── sample-03-argument.svg    + .png
└── sample-04-plate.svg       + .png
```

文件名带页型，方便用户按页型提意见（"第 2 页那个图我要换图型"）。

PNG 导出：宽 1920，2 倍图给 3840。导出后**必须看一眼**——SVG 里字体回退错位、文字溢出，在 PNG 上一眼就看得见，在 SVG 源码里看不出来。

## 七、交付说明（每次给样张必附）

```
这次出了 4 页样张，覆盖结论大字页 / 数据图表页 / 论点支持页 / 图版页。
其中第 2 页按"细"档做到最细——你可以拿它判断我以后每页写到什么颗粒度。

需要你确认三件事：
1. 视觉方向对不对（若我从 3 套候选里出，请指一套）
2. 密度合不合适（太满还是太空）
3. 可编辑边界行不行——第 3 页的关系图我打算用原生形状拼，
   能改但不如精修图好看；第 4 页的图版页是图片，天然不可改文字。

样张上的图都是占位，不是最终的图。
样张不做成品用，后面由落版按规范重做。
```

## 八、自检

- [ ] 3–5 页，≥4 种页型
- [ ] 有一页按细档做到底
- [ ] 每页有"样张·非成品"角标
- [ ] 文字是 `<text>` 未转曲
- [ ] 颜色与令牌逐项一致（不是"差不多"）
- [ ] 字号行高与阶梯一致
- [ ] 图片全是占位并带标签
- [ ] 导出的 PNG 已目视检查，无溢出无错位
- [ ] 附了交付说明，明确三项待确认
