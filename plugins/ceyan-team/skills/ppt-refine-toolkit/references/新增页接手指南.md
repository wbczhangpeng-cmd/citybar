# 新增页接手指南

> 段二专用。用户在 pptx 里手工加了页、贴了图但没排版，你按全篇视觉规则统一排。
> 开工前先读完这一份。

---

## 一、为什么这件事单独成段

主体页面的精修走的是「改 SVG 源 → 重新导出」。而人工新增的页**只在 pptx 里存在，工作区里没有对应的 SVG 源**。所以一旦重新从 SVG 导出，这些页会整体消失。

因此两段分开：

| 段 | 对象 | 改什么 |
|---|---|---|
| 段一 | 项目工作区 | `svg_output/*.svg` → 重新导出 |
| **段二** | **导出后的 pptx** | **只 append 新页，已有页一个字节不动** |

---

## 二、接手前：用户加页的操作规范（要主动交代给用户）

不是解释原理，是给四条能直接照做的规矩：

1. **只做三件事**：新增空白页 → 插入图片 → 保存。**不要在同一个文件里顺手改文字、改母版、改主题**
2. **不要用 WPS 的「一键美化 / 智能换肤 / 统一字体」** —— 它会全局改主题和字体，把已定稿的页一起改了。这是最隐蔽的破坏，事后极难发现
3. **另存为 `.pptx`**（不是 .ppt / .dps，不是"另存 PDF 再转回来"）
4. **两份都在就优先用 PowerPoint** —— 它是 pptx 的原生作者，对包结构改写最小。WPS 另存会重写 theme、字体表和图片压缩参数

---

## 三、接手体检（强制，不过就停）

收到文件先做四项比对，**报一句话结论**：

| 项 | 怎么查 | 不符怎么办 |
|---|---|---|
| **页数** | 原 N 页 + 新增 M 页 = 现在？ | 数量对不上 → 停，问用户是不是删了页 |
| **已有页有没有被改** | 导出前后 PNG 逐页比对（像素差 > 阈值即判变） | 任何一页不符 → **停，不用它继续** |
| **字体表** | 读 `theme.fonts`，与原文件比对 | 被替换 → 停。WPS 常干这事，换完后全篇字重都变 |
| **配色令牌** | 抽样比对主题色与已用色 | 被改 → 停 |

**为什么必须停在"被改过"这一步**：一旦在被改过的底稿上精修，用户最后签的字就等于替别人的改动背书。到时候出了问题，谁都说不清是谁改的。

报结论的样子：

> 体检：原 45 页 + 新增 6 页 = 51 页 ✓；已有页像素比对 45/45 一致 ✓；字体表未变 ✓；配色令牌未变 ✓。可以接手。

或

> 停在体检：P12 与原件不一致（标题位置下移 6px）。这页不是我动的，先确认是你手改的还是 WPS 另存导致的，否则我在这上面排版等于替它背书。

## 四、判页型 → 套版式

新增页一般是纯图页或图文页。**先判它属于哪种形态，再套对应的槽位方案**——不要一页一页即兴发挥，那就是在给全篇制造不一致。

### 形态一：整页大图

```
用途：一张图说明一切（航拍、总平、效果图、场景照）
槽位：图片区 100%（可出血到页边）＋ 标题浮层 or 图注条
规则：
  - 图不裁切主体，等比缩放
  - 标题压在图上必须加蒙层（否则 H4 对比度不达标）
  - 蒙层方向与图上亮部相反（亮天空用深色压，暗夜景用浅色压）
  - 图注三件套放页脚安全区内
标签：实景 / 效果图 / 意向图 / 生成装饰图（见第六节）
```

### 形态二：主图 + 说明

```
用途：一张主图配 2–4 条说明（最常用的新增页形态）
槽位：图片 62–68% ＋ 说明 32–38%（左右分栏）；或上图下文（图 60% / 文 40%）
规则：
  - 说明区文字量按"版面文字"标准：每条 ≤ 25 字，3–5 条
  - 说明与图之间留白 ≥ 令牌间距的 2 档
  - 说明区顶部对齐图片顶部（不是垂直居中——居中会显得悬空）
  - 图注紧贴图片下沿（≤ 60px，规则 S9）
标签：同上
```

### 形态三：多图拼版

```
用途：3–4 张图并列（现状对比、方案比选、场景组图）
槽位：统一裁切比例（全 3:2 或全 16:9，不混用）＋ 统一间距 ＋ 统一圆角（0 或 2px）
规则：
  - 组图 ≤ 4 张
  - 主图 ≥ 50% 面积（不是等分——等分就没有主次，看起来像相册）
  - 每张图单独挂标签
  - 图注统一位置（全在图片下方，或全在右上角，不混）
```

### 形态四：图 + 数据

```
用途：图配一组关键数字（投资构成、客流结构、面积配比）
槽位：图 55–60% ＋ 数据条/数据卡 40–45%
规则：
  - 数字必须是验筹核过的（没核过的标 {待补}，不许自己算）
  - 一页最多 4 个数字卡
  - 数字用数据字号阶梯，不用正文字号放大凑
  - 每个数字带口径（单位 + 期间）
  - **图里不许出现新的数字** —— 那是造数据
```

**四种形态都不是新增页时** → 按 `design_spec` 里最接近的页型处理，并在报告里说明「新增页 X 用了页型 Y（近似）」。**不许为单页新造页型。**

## 五、技术路径

### 默认：append + 原生绘制

```python
from pptx import Presentation
from pptx.util import Emu

prs = Presentation(src_path)

# 用空白版式新增页（不复制任何已有页的版式，避免带入旧占位符）
blank = None
for layout in prs.slide_layouts:
    if layout.name.lower() in ("blank", "空白"):
        blank = layout
        break
slide = prs.slides.add_slide(blank or prs.slide_layouts[-1])

# 画：图片 / 文本框 / 形状 / 表格，全部原生
# 坐标从 design_spec 的栅格算，不要目测
```

要点：

- **已有页不会被重写**。python-pptx 只往 `sldIdLst` 末尾追加，其他页的 XML 不参与序列化差异
- 画完**立即读回同一份 pptx 校验页数**（`len(prs.slides)`），确认没漏
- **字号、颜色、间距全部从 `design_spec` 取**，不要凭感觉给数字——这里是最容易脱轨的地方

### 备选：Edit Native roundtrip

只在新增页需要**复杂矢量**（分析图、装饰图形组合、图标拼合）时用：

```bash
python skills/ppt-master/scripts/pptx_to_svg.py "<src.pptx>" -o "<workspace>" --inheritance-mode both --roundtrip
```

它的契约是「未改动的页被引用并逐字节还原，只有改过的页才重建」。用它的前提：

- 导入后**先做一次未改动页一致性比对**，任何一页不一致立即停
- 只编辑新增页，其他页保持 referenced 状态
- 导出后仍要跑两个检查脚本

**风险要说清**：复杂图形、嵌入对象、部分图表在导入时可能被降级成代理对象。所以它是备选，不是默认。

## 六、图元真实性五级（沿用立象的定义，不放宽）

| 标签 | 含义 | 红线 |
|---|---|---|
| **实景照片** | 项目现场或周边真实照片 | 须有版权或甲方提供 |
| **效果图** | 设计单位出具的效果图 | **AI 不得代出** |
| **分析图** | 基于已核验数据的分析图 | 数据须来自验筹事实包 |
| **意向图** | 氛围与风格参考 | 图片上必须标「意向图」字样；可 AI 生成 |
| **生成装饰图** | 纯氛围背景 | **不得承载任何数据或空间主张** |

**三条绝对红线**：

1. AI 生成图不得承载数据
2. AI 生成图不得冒充实景照片
3. AI 生成图不得冒充本项目效果图

违反了不是"不够严谨"，是**伪造设计方案**。汇报现场被问一句"这是哪个角度拍的"就穿帮。

## 七、缺口怎么办

| 情形 | 处理 |
|---|---|
| 甲方该给的实景还没到 | **保留显式占位**（灰底 + 图名 + "待提供"）＋ 进《缺口清单》。不用网图顶 |
| 效果图没出 | 同上。**不拿意向图当效果图** |
| 用户说"你随便找张图先放着" | 回一句：「那我按意向图放，图上标'意向图'字样，可以吗」——让他明确，别默认 |
| 图的比例与原蓝图槽位冲突 | 位内适配（等比缩放 + 居中裁切）算 L1；需要改分区比例算 L2，先给用户看 |

## 八、交付前自检

- [ ] 页数 = 原页数 + 新增页数，一页不少
- [ ] 已有页**一个都没动**（像素比对通过）
- [ ] 新增页用的是 `design_spec` 的令牌与页型，没有新造页型
- [ ] 四种形态各自的槽位规则都遵守了（主图面积、间距统一、裁切比例统一）
- [ ] 每张图都挂了标签，AI 图都标了「意向图」
- [ ] 每页都有页码，位置与全篇一致
- [ ] 图注三件套齐（图名 · 来源 · 标签）
- [ ] 新页过了 `check_editability.py`（文字可选中、无整页位图）
- [ ] 新页过了 `check_deck_consistency.py`（字号、颜色、页码位置与全篇一致）
- [ ] 出过前后对比图，用户确认过
