# 页型到生成映射

立象定义了 15 种页型。这里给的是**每种页型落成 PPT 时的构造方式**——用什么原生构件、哪里最容易翻车、可编辑性红线在哪。

页型不是可选项：**用错主页型 = 结构级偏离，必须先问用户。** 用对页型但换了变体 = 微调，记账即可。

---

## 1. 封面

- **构造**：标题 + 副标题 + 汇报单位/日期，三块原生文本框；背景为整幅图或纯色块
- **易错**：背景图压暗不够导致标题读不清；标题用艺术字转曲
- **红线**：标题必须原生文本框，**不许把标题画进背景图**

## 2. 目录

- **构造**：章序号 + 章名 +（可选）页码，逐行原生文本；不要用表格伪装
- **易错**：页码与实际页不符（增删页后必查）；章名与章扉页不一致
- **提醒**：目录是**全篇最容易失效的一页**。任何页序变动，第一件事回来改它

## 3. 章节扉页

- **构造**：大章序号 + 章名 + 一句导语；强留白
- **易错**：导语写成下一个论点（抢了正文的活）；章的编号风格与目录不统一

## 4. 结论大字页（一页纸结论 / 执行摘要）

- **构造**：一句主结论（超大字号，占 50–60%）+ 3–4 条支撑（每条一行）+ 页脚出处
- **易错**：主结论写成名词短语（"项目定位"）而不是判断句（"应做成 X 而非 Y"）；支撑条数塞到 6 条以上，大字页退化成列表页
- **红线**：主结论那句**必须是原生文本**——客户最常要改的就是这句

## 5. 论点支持页（全篇主力，占比应最高）

- **构造**：顶部一句结论 + 3–5 条支撑，每条含小标题与一行说明；左右或上下分区
- **变体**：左文右图 / 上文下图 / 三列并置 / 图文交错
- **易错**：每条支撑写成一段话（这不是正文，是幻灯片）；三条支撑视觉权重完全相等，没有主次
- **可编辑**：卡片框用原生矩形，**不要用一张切好的九宫格图**

## 6. 数据图表页

- **构造**：一句结论式图标题 + 原生图表对象 + 数据源脚注
- **图表选型**：趋势用折线、构成用堆叠柱或条形、对比用分组柱、占比 ≤5 项用饼、指标达成用子弹或进度条
- **易错**：标题写成"客流量分析"（名词）而非结论；口径三件套（单位/期间/口径定义）缺一；数值靠图例猜
- **红线**：**图表必须是原生图表对象**（可改数据）。截图、SVG 图画出来的"图表"一律不合格
- **注**：需要原生图表时导出加 `--native-charts-and-tables`

## 7. 表格对比页

- **构造**：原生表格，表头一行、数据行 ≤8、关键列加粗或底色
- **易错**：表格塞满整页变成 Excel 截图；对比维度太多（>6 列）失去可读性；合计行忘加
- **红线**：**原生表格**，不许贴图；8 张表的正文页做"简化版"，全量进附录

## 8. 矩阵模型页（2×2 / 定位矩阵 / 功能配比）

- **构造**：两条轴线（原生线条 + 轴标签）+ 象限底色块 + 定位点（原生圆/菱形）+ 标签
- **易错**：轴线刻度缺失导致象限含义不清；定位点没有标注对应哪个方案
- **可编辑**：象限用原生形状拼，**绝不整张矩阵画成一张图**

## 9. 关系结构图页（业态组合 / 功能结构）

- **构造**：原生形状（矩形/圆角矩形/圆）+ 原生连接线 + 文本标签
- **易错**：连线没有绑定到形状（一挪就断）；层级深度超过 3 层，一页看不完
- **红线**：复杂关系图**必须用原生形状拼**。这是"整页截图"最高发的地方——一张漂亮的关系图 PNG 塞进去，等于这页永远改不了

## 10. 时间轴 / 分期路线图

- **构造**：主轴一条原生线 + 节点（原生圆）+ 阶段块 + 阶段标签；横向为主
- **易错**：阶段与分期投资表对不上（跨表一致性，需回查）；时间刻度不等距却不标注
- **提醒**：分期图是全篇最容易被验筹挑出矛盾的一页（分期 vs 收益起算年），画之前先核一遍

## 11. 地图区位页

- **构造**：地图底图（图片，须合规来源）+ 原生标注点与引线 + 方位/比例尺
- **易错**：地图来源不合规（中国地图必须有审图号或使用合规底图）；标注点位置靠目测
- **红线**：**地图底图必须是合规来源**，不得用 AI 生成的地图当区位图

## 12. 图版页

- **构造**：全页统一裁切比例（3:2 或 16:9，不混用）、统一间距、圆角统一；组图 ≤4 张，主图 ≥50% 面积
- **易错**：混用不同比例的图；每张图忘挂标签（实景/效果图/意向图/生成图）
- **红线**：**每张图必挂标签**，标签是合规要求不是装饰

## 13. 技术图纸页

- **构造**：**只有标题文本框 + 符合整体风格的背景，其余全部留空**。图框后期自行添加
- **易错**：画蛇添足加装饰边框、加图注占位、加"平面图"文字框——**都不要**，用户会自己放图
- **这条按用户明确要求执行**：留空是刻意的，不是没做完

## 14. 附录页

- **构造**：8 张表全量；原生表格为主，宽表可横排或缩小字号；每表独立起页或两表一页
- **易错**：附录字号跟着正文一样大导致溢出；表格跨页断开无续表标识

## 15. 结语 / 下一步页

- **构造**：一句收束 + 3 条下一步（谁、做什么、什么时候）+ 联系信息
- **易错**：下一步写成空话（"持续优化""深化研究"）；三条没有责任主体

---

## 通用构造纪律

1. **文本永远是文本**。任何承载信息的文字，必须能被选中、能被改。包括图表标题、图注、标签、脚注。
2. **形状用原生**。矩形、圆、线、箭头、连接线——都是原生对象，可改色可挪位。
3. **连接线要绑定**。形状之间的连线用绑定到形状的连接线，不要画成独立线段（一挪就散）。
4. **一页的图层不要超过必要的嵌套**。分组是为了好改，不是为了好看。
5. **复用靠页型，不靠复制粘贴**。同页型的页面共用同一套槽位逻辑；靠复制改文字最容易漏改（页码、章名、图注）。
